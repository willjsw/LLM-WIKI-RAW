# 공유 메모리 기반 C 서비스의 패키지 교체와 원복

## Purpose

공유 메모리를 쓰는 C 서비스 바이너리를 새 버전으로 교체하고, 문제가 생기면 이전 상태로 되돌린다.

## Steps

1. 백업: 실행 바이너리 디렉토리(bin, cmd, build, 라이브러리)와 설정 디렉토리(conf, script)를 날짜가 들어간 tar 로 각각 묶고 `ls -al` 로 크기를 확인한다.
2. 사전 작업: 필요한 DB 스키마 변경(컬럼 추가는 기본값을 두어 기존 코드와 호환)과 명령 정의 파일 수정을 먼저 반영한다.
3. 빌드: `make clean` 후 `make install`.
4. 서비스 전체 중지 후 남은 프로세스를 강제 종료한다.
5. 기존 공유 메모리 세그먼트를 삭제한다. 구조체 레이아웃이 바뀐 새 바이너리가 예전 세그먼트에 붙으면 데이터가 어긋난다.
6. 빌드 산출물을 실행 디렉토리로 복사하고 서비스를 시작한다.
7. 원복: 전체 중지 → 프로세스 강제 종료 → 공유 메모리 삭제 → 바이너리 백업 tar 해제 → 설정 백업 tar 해제 → 재시작.
