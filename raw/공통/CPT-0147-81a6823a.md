# DTMF

## Definition

DTMF(Dual-Tone Multi-Frequency)는 전화 버튼을 누를 때 저주파 하나와 고주파 하나를 동시에 내는 두 톤 조합으로 숫자를 전달하는 신호 방식이다.

## Evidence

- 0-9, *, #, A-D 를 표현하며 ARS·IVR 메뉴 선택, 인증 번호 입력 등 자동 응답 시스템에 쓰인다.
- VoIP 에서는 음성에 섞어 보내는 대신 SIP INFO 나 RTP 이벤트(RFC 2833) 같은 별도 방식으로 전달하기도 하며, 교환기 라우트 설정에서 전달 방식을 고른다.
