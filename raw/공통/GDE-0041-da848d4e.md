# 문서 저장소 온톨로지 단계별 구축

## Purpose

문서 저장소를 관계 질의(어떤 대상에 영향을 준 결정과 장애 등)가 가능한 지식그래프로 만들 때, 엔티티 해소와 엣지 추출이 LLM 추론에만 기대지 않도록 단계적으로 기반을 쌓는다.

## Steps

1. 용어집과 엔티티 DB 를 작성한다(고객사, 시스템 컴포넌트, 약어). 산출물은 노드 사전과 표준 표기다. 같은 대상의 여러 표기를 하나로 모은다.
2. 문서에 엔티티와 관련 문서 관계(Relation)를 연결한다. 이것이 그래프의 엣지가 된다.
3. 회의록의 결정사항을 결정 유형 문서로 분리하고 근거 문서를 연결한다. 결정 → 근거 추적이 가능해진다.
4. 프론트매터가 포함된 md 미러를 그래프로 변환(graphify 등)해 질의·시각화한다.
5. 각 문서에 type 을 붙여 노드 클래스를 정하고, 의미 없는 계층(제목 없는 DB, 빈 단계 폴더)은 정리해 경로가 맥락 신호가 되게 한다.
