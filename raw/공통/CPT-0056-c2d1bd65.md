# 엔드포인트 관리의 Shift Left와 DEX

## Definition

엔드포인트 관리의 Shift Left는 문제가 생긴 뒤 대응하던 방식에서, 알려진 문제를 사용자에게 영향이 가기 전에 조치하고 나아가 발생할 문제를 예측해 막는 방향으로 옮기는 것이다. DEX는 단말의 경량 에이전트로 문제를 감지·조치해 직원의 디지털 경험을 관리하는 접근이다.

## Evidence

- 단말 에이전트는 오프라인에서도 동작하는 정책을 내장한다
- 한 번 해결된 문제는 자산화해, 같은 증상을 보이는 다른 단말에 자동으로 조치 스크립트를 실행한다
- 자동 보고서로 단말 문제 패턴(원인·영향도·해결방안)과 소프트웨어 버전별 안정성을 파악한다
- 크리티컬 패치는 즉시 조치하고, 미승인 소프트웨어 삭제처럼 영향이 큰 조치는 관리자 승인 워크플로를 태운다
- 신규 입사자 프린터 연동, 디스크 정리 같은 반복 요청을 자동화하고, 디바이스 교체 주기를 실제 사용 패턴으로 판단한다
