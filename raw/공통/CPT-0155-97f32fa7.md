# 노트 타입별 상태 머신과 가변성

## Definition

노트의 생명주기를 폴더 이동 대신 타입마다 정해진 상태값과 가변성으로 표현하는 방식이다. 기록형(snapshot) 노트는 확정되면 의미 내용을 고치지 않고 새 노트로 대체하며, 현재형(current) 노트는 현재 상태를 서술하므로 계속 고친다.

## Evidence

- snapshot: decision, observation, source. 틀렸으면 고치지 않고 새 노트를 만들고 `superseded_by` 로 잇는다.
- current: concept, guide, analysis, area. `draft → stable → deprecated`.
- 실행 추적용(task, project)은 가변성 개념 없이 진행 상태만 둔다(task: todo → doing → done/cancelled, project: planned → active → done/cancelled).
- decision: `proposed → accepted / rejected → superseded`. observation: `draft → recorded`. source: active 와 별도 반입 상태(raw → triaged → normalized).
- 모든 타입은 `tombstone`(이전 상태, 제거 시각, 리다이렉트 대상 기록)으로 갈 수 있다.
- AI 가 만든 노트는 첫 상태로만 쓰고, 첫 상태를 벗어나는 확정 전이는 사람이 확인한다.
- 효과: 상태와 의미가 머리말에 있으므로 폴더를 옮겨도 의미와 관계가 깨지지 않고, "끝남·틀림·대체됨·버림"을 구분해 표현할 수 있다.
