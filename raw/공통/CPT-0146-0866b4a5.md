# 교환기 인바운드와 아웃바운드 호 라우팅 흐름

## Definition

인바운드 호는 통신사 SIP 트렁크로 들어와 라우트 시그널·라우트를 거쳐 번호가 조작된 뒤 VDN 시나리오로 넘어간다. 아웃바운드 호는 다이얼 플랜으로 번호 종류를 판정하고 번호 분석(Number Analysis)으로 라우트 그룹을 고른 뒤 라우트 시그널로 나갈 통신사를 정한다.

## Evidence

- 다이얼 플랜: 내선, 상담원 번호, 외부 발신 접두(예: 9 + 외부번호) 같은 번호 체계를 정의한다.
- 번호 분석: 외부 발신 번호를 보고 어떤 라우트 그룹을 탈지, 앞자리 몇 개를 지울지 정한다.
- 라우트 방향은 발신(origin, outbound)과 착신(destination, inbound)으로 나뉘며 양방향(BOTH)도 있다.
- 발신 표시 번호는 라우트의 표시 이름, 내선의 공개 표시 번호 순으로 정하고 둘 다 없으면 라우트 기본 삽입 번호가 붙는다.
- 착신 전환(포워딩)이 끼면 과금 대표번호를 Diversion 헤더로 넘긴다.
- FAC(Feature Access Code)는 단말에서 코드를 눌러 착신 전환·당겨받기 같은 기능을 쓰게 한다.
