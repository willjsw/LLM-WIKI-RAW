# VDN과 DNIS, 인입 VDN과 상담 연결 VDN

## Definition

VDN(Vector Directory Number)은 수신된 콜을 처리할 벡터(라우팅 스크립트)를 가리키는 번호이고, DNIS는 고객이 기업의 어떤 번호로 전화했는지 식별하는 번호다. 시스템은 DNIS를 특정 VDN으로 매핑하며, 최초 인입 VDN의 DNIS를 Original DNIS로 끝까지 유지한다.

## Evidence

- 콜 흐름 예: IVR VDN → 상담 연결 VDN → 상담원 연결(Established) → 호전환 → 상담 연결 VDN → 종료(Call Cleared). 호전환되면 같은 VDN이 다시 인입될 수 있다.
- 인입 VDN은 대표번호(센터) 단위 실적을, 상담 연결 VDN은 요청·응대 호를 본다. 여러 센터가 스킬을 공유하면 스킬 통계에 다른 센터 실적이 섞이므로, 모든 이벤트에 인입 VDN을 넣어 센터별로 나눈다.
- Original DNIS는 IVR 인입에서만 부여되고, IVR 재인입이나 호전환 뒤에도 최초 인입 정보를 유지한다.
- VDN과 큐는 1:1이 아니다. 상담 연결 플로우에서 큐 전환을 여러 번 하면 한 VDN 아래 큐가 여러 개 생긴다. 그래서 큐 통계 테이블에도 VDN 키가 필요하다.
- 인입 건수는 VDN Delivered 이벤트, 인바운드 응대 건수는 상담 연결 VDN의 Established 이벤트로 셀 수 있어 상담원 단말 이벤트를 모두 볼 필요는 없다.
