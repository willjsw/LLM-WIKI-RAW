# AI 친화 문서 메타데이터 스키마

## Definition

문서마다 유형·영역·수명주기·신뢰 상태·담당자·검토일·요약·엔티티·관계·AI 공개 범위를 구조화된 필드로 붙여, 사람의 필터와 AI 의 검색 필터·근거 선택·노출 통제에 함께 쓰는 스키마다. Notion 속성과 md 미러의 YAML 프론트매터를 1:1 로 맞춘다.

## Evidence

필드와 각 필드가 AI 에 주는 효과:
- `type` (manual · design · reference · meeting · incident · decision): 노드 클래스, 검색 필터, 템플릿 자동 적용.
- `domain`: 검색 범위 축소.
- `para` (project · area · resource · archive): archive 는 기본 검색에서 제외.
- `status` (draft · reviewed · canonical · deprecated): 표준(canonical) 문서만 정답 근거로 사용.
- `owner`: 갱신 책임, 출처 표시.
- `reviewed_at`: 오래된 문서 탐지(예: 90일 경과 시 뷰에 노출), 최신성 가중치.
- `summary` (1~2문장): 목록 미리보기, 검색 스니펫, 저비용 컨텍스트.
- `entities`: 엔티티 DB 표준 표기로 적어 온톨로지 엣지가 된다.
- `related.supersedes` / `related.evidence`: 정본 판별, 결정 근거 추적.
- `ai_access` (public · internal · restricted): MCP·RAG 노출 범위 통제. MCP 리소스로는 status=canonical 이고 ai_access≠restricted 인 문서만 노출한다.
