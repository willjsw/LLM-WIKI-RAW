# DNIS 와 DID

## Definition

DNIS(Dialed Number Identification Service)는 발신자가 실제로 건 착신 번호를 교환기에 알려주는 정보이고, DID(Direct Inward Dialing)는 외부에서 내선으로 바로 걸리도록 내선에 부여한 외부 공개 번호다.

## Evidence

- 멀티 테넌트 교환기는 인입 호의 DNIS 로 어느 테넌트(고객사) 자원인지 판별한다. 대표번호와 종속 번호를 DNIS 로 구분한다.
- 내선의 공개 번호(public number)가 DID 이며, 같은 번호가 두 내선에 붙지 않도록 중복 체크가 필요하다.
- 회사 대표 발신 번호처럼 여러 내선에 일괄 적용할 값은 내선마다 바꾸지 않고 라우트에서 번호를 조작해 처리한다.
