# VDN 과 ACD 헌트 그룹

## Definition

VDN(Vector Directory Number)은 실제 단말이 없는 논리 번호로, 호가 들어오면 연결된 벡터(시나리오)를 실행한다. ACD 그룹(헌트 그룹, 스킬 그룹)은 대기 큐와 상담원 묶음으로, 벡터가 호를 이 그룹에 넣으면 조건에 맞는 상담원에게 배정된다.

## Evidence

- 일반적 흐름: 대표번호 → 인입 VDN → (메뉴 선택) → 상담 VDN → ACD 그룹 → 상담원 내선.
- 콜백 기능이 있으면 콜백용 VDN 을 따로 만든다. 안내·경고 멘트용 VDN 도 고객사마다 둔다.
- Avaya 용어로 ACD 그룹은 hunt group, 시나리오는 vector 다.
- 상담원은 여러 스킬 그룹에 속할 수 있고(멀티 스킬), 스킬 레벨과 큐 우선순위로 배정 순서를 조정한다.
- IVR 채널도 하나의 그룹으로 묶어 관리한다.
