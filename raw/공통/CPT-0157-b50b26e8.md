# 노트의 병합·대체·분할·삭제·보관 표현 분리

## Definition

노트에 일어나는 사건을 각각 다른 머리말 표기로 남겨, 폴더 이동 하나로 뭉뚱그리지 않는 규칙이다. 참조 무결성을 지키기 위해 참조되는 노트는 실제로 지우지 않고 묘비(tombstone) 상태로 남긴다.

## Evidence

- 병합: 흡수된 쪽을 `status: tombstone` + `redirect_to: <남는 id>` 로 둔다.
- 대체: 이전 노트에 `superseded_by: <새 id>`.
- 분할: 원본은 유지하고 새 노트에 `extracted_from` 을 단다.
- 삭제: 참조되는 노트는 지우지 않고 tombstone(이전 상태, 제거 시각 기록). 번호(id)는 재사용하지 않는다.
- 보관: 아카이브 폴더 이동은 정리 편의일 뿐이고 의미는 `status` 가 결정한다.
- 관계는 경로 대신 영구 id 로 기록하므로 파일을 옮겨도 깨지지 않는다. 위키링크는 탐색용으로만 쓰고 의미 관계는 방향이 있는 필드로 적는다(대칭형 related 금지).
- 대조: 위치 이동형 볼트에서는 끝남·틀림·대체됨·버림이 모두 Archive 이동 하나로 표현되고, 왜 옮겼는지가 문서에 남지 않는다.
