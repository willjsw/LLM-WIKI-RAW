# 팀 문서 저장소 운영 규칙

## Purpose

정리한 문서 저장소가 다시 흩어지고 낡지 않도록 작성·정리 습관을 규칙으로 고정한다.

## Steps

1. 날짜는 속성으로 관리하고 제목에서 뺀다. 넣어야 하면 `YYYY-MM-DD 제목` 한 가지로 통일한다. 고객사·시스템명은 엔티티(용어집) 표기만 쓴다.
2. 문서 하나에 위치 하나. 다른 곳에서는 링크나 Linked View 로만 참조하고 사본(`(1)`)을 만들지 않는다. 개정판은 "대체함" 관계로 이전 문서와 잇는다.
3. 계정·비밀번호는 문서에 쓰지 않고 사내 비밀정보 저장소 링크만 기록한다. 기존 평문 자격증명 이전이 가장 먼저 할 일이다.
4. 긴 로그는 토글 안에 넣고 본문에는 요약 3줄을 쓴다.
5. 월 1회 30분, "90일 미검토" 뷰를 확인해 갱신·보관·폐기 중 하나로 처리한다.
6. 생성 후 7일 동안 본문이 없는 문서는 삭제 대상으로 본다.
7. 분기 1회 대표 질문 10개를 AI 에 질의해 정확도를 점검하고 틀린 답의 원인 문서를 고친다.
8. 도입 순서는 보안 위험 해소(자격증명 이전) → 빈 문서·사본 정리 → 공통 속성·템플릿 확정 → 용어집·엔티티 → 중복 통합 → 이력 DB 이관 → 진입점·영역 인덱스 → md 미러 시범으로 한다.
