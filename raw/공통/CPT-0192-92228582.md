# AI 생성 코드의 신뢰 구조와 인간 개입 지점

## Definition

AI가 만든 코드를 믿을 근거를 AI 자신의 리뷰가 아니라 컴파일러, 정적 분석, 기존 회귀 테스트, 리플레이·시뮬레이션, 보안 스캐너 같은 독립 검증에서 얻는 구조다. 흐름은 사람의 의도·명세 → AI 구현 → 자동 검증 → 독립 AI 리뷰 → 증거 → 사람의 결정이다.

## Evidence

- 낮은 신뢰 구조: AI 구현 → AI가 만든 테스트 → AI 자기 리뷰 → '문제 없음'.
- 사람이 모든 코드를 직접 리뷰하면 생산성 상한이 개발자 본인의 실력에 묶인다.
- 역할 분담: AI는 코드 생성·수정, 테스트 생성, 반복 실행, 정적 분석, 일반 리뷰, 문서 갱신. 사람은 문제 정의와 우선순위, 요구사항과 인수 기준, 아키텍처와 정책, 리스크와 트레이드오프, 예외 판단, 최종 승인.
- 관심이 기능(MCP, Skill, 프롬프트)에서 시스템(무엇을 맡기고, 어떤 맥락을 주고, 어떻게 검증하고, 어디서 개입할지)으로 옮겨 간다.
- 만든 과정(맥락, 프롬프트, 지침)을 남겨 제품 생산 시스템으로 관리한다.
