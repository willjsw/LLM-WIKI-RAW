# AI 코딩 에이전트에 큰 단위 작업을 추적 가능하게 위임하기

## Purpose

AI 에이전트에 기능 단위 작업을 맡기면서도 사람이 진행을 추적하고 결과를 검증할 수 있게 한다.

## Steps

1. 사람이 요구 분석과 현황 분석을 먼저 하고, AI와 함께 PRD(요구 문서)를 쓴다.
2. PRD를 태스크 관리 도구(예: Taskmaster)로 세부 태스크로 쪼갠다. 이슈 트래커와 1:1로 맞춘다(태스크 1건 = 이슈 1건, PRD 1건 = MR 1건 = Epic 1건).
3. 태스크마다 작업 계획서 md를 만든다. 이 문서를 구현 AI와 리뷰 AI가 함께 참조해 작업에 대한 공통 이해를 만든다.
4. 실행 전에 Plan 모드로 계획을 검토하고, 자동 승인·권한 우회 모드는 쓰지 않고 단계별로 변경을 확인한다.
5. 태스크 단위로 커밋하게 하고 `git show`, `git diff`로 변경을 확인한다.
6. 테스트와 실제 서버 구동, DB 조회로 실데이터 검증을 한다.
7. 맥락은 CLAUDE.md(공통 + 프로젝트별)와 정리된 문서·메타데이터로 계속 갱신해 제공한다.
8. 외부 시스템(이슈 트래커, Git 호스팅, 메신저) 접근은 CLI 권한이나 MCP 도구로 통제된 경로를 준다.
