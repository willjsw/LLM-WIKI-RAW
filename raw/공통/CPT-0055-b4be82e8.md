# 에이전트형 가상 상담원의 구성 — 행동, 도구, 지식

## Definition

에이전트형 가상 상담원은 답변 문장을 만드는 데 그치지 않고 실제 요청을 처리하는 3세대 상담 자동화다. 설계 대상은 할 수 있는 일의 경계(행동), 실행 수단(도구), 판단 근거(지식) 세 가지이며, 플로우 차트 대신 이 셋을 문서로 정의한다.

## Evidence

- 세대: 1세대 IVR → 2세대 음성봇·챗봇 → 3세대 에이전트형 상담원. 구분 기준은 답변 생성인가 요청 처리인가다
- 기존 ARS·챗봇의 한계: 메뉴를 타고 내려가야 하는 대기, 정해진 발화 패턴 밖은 처리 불가, 고객이 시스템 구조에 맞춰 말해야 하는 시스템 중심 구조
- 행동: 업무 범위, 가이드라인, 가드레일 정의
- 도구: 의도에 맞는 MCP Tool 호출로 백엔드와 연동하고 필요할 때 도구를 추가해 확장
- 지식: 지식 항목에 구체적 이름을 붙이고 명시적 지침을 쓰며 RAG로 검색
- 음성 채널에서 실제로 성립하는지는 응답 지연 문제와 함께 별도 확인이 필요하다
