# 세션 키 없는 집계 뷰에서 케이스별 기여분 측정

## Purpose

시간 버킷 집계 뷰에는 세션·콜 키가 없어 특정 테스트 케이스의 기여분을 직접 조회할 수 없다. 스냅샷 차분으로 케이스별 값을 얻는다.

## Steps

1. 회차 시작 시각을 조회 창 시작으로 고정해 저장한다. 창을 매번 다시 잡으면 창이 줄어 가짜 음수 델타가 생긴다.
2. 각 케이스 경계마다 진행 중인 집계 블럭을 재적재한 뒤 대상 집계 뷰들을 통째로 스냅샷한다. 재적재 전 스냅샷은 값이 맞지 않는다.
3. 인접 스냅샷의 차를 그 케이스의 기여분으로 본다.
4. 블럭 안 세션 수가 회차의 콜 수보다 많으면 운영 콜 혼입 경고를 낸다. 판정은 바꾸지 않는다.
5. 결과는 판정하지 않고 기대값·정답지와 나란히 놓는다. 환경의 대상 ID 집합과 테스트 상담사 ID 로 '우리 칸 / 남의 칸'을 가른다.
6. 재적재는 그 블럭의 운영 데이터까지 다시 계산해 되돌릴 수 없으므로 운영 트래픽이 없는 시간대에만 실행한다.
