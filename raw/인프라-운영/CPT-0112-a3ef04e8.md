# Docker bind mount 와 managed volume

## Definition

bind mount 는 호스트의 특정 경로를 컨테이너에 그대로 연결하고, managed volume 은 Docker 엔진이 관리하는 저장소를 이름으로 연결한다. 둘 다 `docker run -v` 로 지정한다.

## Evidence

- Bind mount: `-v /host/html:/usr/share/nginx/html`, 끝에 `:ro` 를 붙이면 컨테이너 안에서 읽기 전용이다.
- Managed volume: `docker volume create db_data` 후 `-v db_data:/var/lib/mysql`. `docker volume ls`, `docker volume rm` 으로 관리한다.
- 리눅스에서 managed volume 실체는 `/var/lib/docker/volumes/<이름>/_data`(root 필요). macOS·Windows 는 VM 안에 있으므로 Docker Desktop 이나 임시 컨테이너(`docker run --rm -it -v db_data:/data alpine sh`)로 들여다본다.
- `docker inspect -f "{{ .Mounts }}" <c>` 로 마운트 정보를 확인한다.
- `docker rm -v` 는 연결된 볼륨까지 지우고, `docker system prune --volumes` 는 어떤 컨테이너와도 연결되지 않은 볼륨을 모두 지운다.
