# OWASP Dependency-Check로 Java 의존성 취약점 검사

## Purpose

빌드 의존성에 알려진 취약 버전(CVE)이 포함됐는지 확인하고 HTML 리포트를 만든다.

## Steps

1. NVD 공식 사이트에서 API 키를 발급받는다. 키 없이도 동작하지만 취약점 DB 다운로드가 매우 느리다. 키는 코드나 빌드 파일에 넣지 말고 환경변수(`NVD_API_KEY`)로 넘긴다.
2. CLI: `dependency-check.sh --nvdApiKey "$NVD_API_KEY" --project <이름> --scan ./`.
3. Maven: `org.owasp:dependency-check-maven` 플러그인을 추가하고 format을 HTML로 둔 뒤 `mvn dependency-check:check`.
4. Gradle: 플러그인 ID는 Maven과 다른 `org.owasp.dependencycheck`다. `dependencyCheck { formats = ['HTML']; nvd { apiKey = System.getenv('NVD_API_KEY') } }` 설정 후 `./gradlew dependencyCheckAnalyze`. 리포트는 `build/reports/dependency-check-report.html`.
5. `check` 태스크에 묶으려면 `tasks.named('check') { dependsOn('dependencyCheckAnalyze') }`.
6. 결과 조치: 프레임워크(BOM)를 먼저 올리고, BOM이 아직 반영하지 않은 취약 라이브러리는 Maven `<properties>`의 버전 프로퍼티(예: `log4j2.version`, `commons-lang3.version`)로 개별 오버라이드한다.
7. 검사는 오래 걸리므로 CI에서는 캐시를 쓰거나 주기 실행으로 돌린다. Maven과 Gradle 플러그인 릴리스 번호는 항상 같지 않다.
