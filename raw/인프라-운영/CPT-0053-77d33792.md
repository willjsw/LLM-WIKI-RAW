# 쿠버네티스 API 플랫폼의 Graceful Shutdown

## Definition

Graceful Shutdown은 Pod가 종료될 때 진행 중인 요청(거래)을 완전히 끝낸 뒤 내려가도록 애플리케이션 종료 순서와 Pod 종료 시간을 제어하는 것이다. 금융 API처럼 요청 유실이 허용되지 않는 서비스에서 무중단 배포의 전제다.

## Evidence

- Readiness Probe로 종료 대상 Pod에 새 트래픽이 들어오지 않게 한 뒤 진행 중 요청을 마무리한다
- 배포는 블루그린/카나리/롤링 중 롤링을 택하고 핵심 API 서버부터 순차 배포한 사례가 있다
- 같은 플랫폼에서 비동기 처리·비동기 로깅, 민감정보 암호화의 별도 스레드 처리, 분산 캐시의 Pod 간 공유 지연 고려, 정기 전송 시간대 외 Scale-in을 함께 적용했다
- 배경 개념: 임베디드 금융은 비금융 서비스 안에 금융 서비스가 내장되는 형태이고, BaaS는 이를 API로 제공하는 기술 기반이다
