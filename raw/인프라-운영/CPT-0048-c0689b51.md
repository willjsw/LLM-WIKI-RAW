# ContextLake와 컨텍스트 패키징

## Definition

ContextLake는 원시 데이터 대신 자연어 맥락·판정 근거·관계 맥락이 흐르도록 설계한 LLM 시대의 데이터 레이크 개념이다. 추론 결과를 점수뿐 아니라 배경과 비즈니스 맥락과 함께 묶어 LLM에 제공한다.

## Evidence

- "데이터가 흐른다 → 의미가 흐른다"
- 시계열·로그 테이블·지표 JSON을 자연어 맥락, 판정 근거, 관계 맥락으로 변환한다
- 컨텍스트 패키징 4요소: ① 비즈니스 배경 설명·용어 사전 ② 모델링 과정 설명 ③ 추론 배경 통계(정규분포, 이동평균 등) ④ 추론 결과와 시각화
- MCP 허브로 분 단위 조회를 제공한다
- "LLM은 맥락만 있다면 전문가가 된다" — 에이전트는 상황에 따라 정보량을 조절해 중요한 것만 선별한다
