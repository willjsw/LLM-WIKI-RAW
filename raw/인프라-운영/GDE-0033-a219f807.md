# 오프라인 환경에서 RPM 묶음 일괄 설치

## Purpose

인터넷이 없는 RHEL 계열 서버에 반입한 RPM 파일들을 의존성 순서 고민 없이 설치한다.

## Steps

1. 필요한 rpm 과 그 의존성 rpm 을 한 디렉토리에 모아 반입한다.
2. 파일을 한 번에 모두 넘겨 rpm 이 묶음 안에서 상호 의존성을 해결하게 한다: `sudo rpm -ivh <dir>/*.rpm`. RPM DB 에 쓰므로 root 권한이 필요하다.
3. 이미 설치된 패키지와 충돌하면 `-Uvh` 로 업그레이드 설치한다.
4. 의존성 오류가 나면 오류에 나온 패키지가 묶음에 들어 있는지 확인하고 빠진 rpm 을 추가 반입한다.
5. 인터넷이나 로컬 미러가 연결된 서버라면 `sudo dnf install -y <dir>/*.rpm` 이 로컬 파일을 설치하면서 부족한 의존성을 repo 에서 채워 준다(옛 yum localinstall 역할). 오프라인에서는 쓸 수 없다.
6. 스크립트가 쓰는 도구(예: jq)가 실제로 설치됐는지 `command -v jq && jq --version` 으로 확인한다.
