# 서비스 이미지는 바이너리 내장 설정 외부 주입으로 만든다

## Definition

서비스 이미지에는 실행 바이너리(jar 등)만 넣고 설정은 외부에서 주입하며, 볼륨은 설정과 로그(필요하면 데이터)만 마운트하는 이미지 작성 원칙이다.

## Evidence

- Dockerfile 을 전달하지 않고 빌드된 이미지를 저장소에 올려 받아 쓰게 한다.
- 모듈별로 컨테이너를 분리한다.
- 컨테이너 안팎의 디렉토리 구조(/app, /logs, /data 아래 시스템명)를 일치시켜 운영자가 경로를 헷갈리지 않게 한다.
- 현장은 home 아래 계정 정보를 두지 않는 경우가 많아 경로를 home 기준으로 잡지 않는다.
- 로그 로테이션과 보관 기간을 이미지 단계에서 정한다.
