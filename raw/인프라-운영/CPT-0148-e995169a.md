# systemd Restart 정책과 종료 코드 0

## Definition

systemd 서비스의 `Restart=on-failure` 는 비정상 종료(0 이 아닌 종료 코드, 시그널 사망 등)일 때만 재시작하고, `Restart=always` 는 정상 종료(코드 0)여도 재시작한다.

## Evidence

- 감독 프로세스가 의도적으로 코드 0 으로 종료하면 on-failure 에서는 내려간 채로 남고, always 에서는 바로 다시 올라온다.
- always 로 두면 "하위 프로세스까지 모두 정리하고 0 으로 종료"가 깨끗한 전체 재시작 트리거가 된다. 종료 전에 하위 프로세스가 확실히 죽었는지 확인해야 재기동 시 중복 기동이 없다.
- systemd 없이 배포 스크립트로만 띄운 프로세스는 종료 후 스크립트를 다시 실행해야 올라온다.
