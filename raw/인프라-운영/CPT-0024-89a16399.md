# MDC로 스레드 로그에 요청 문맥 붙이기

## Definition

MDC(Mapped Diagnostic Context)는 SLF4J·Logback 같은 자바 로깅 프레임워크에서 현재 스레드에 Key-Value 문맥 정보를 저장해, 그 스레드에서 찍는 모든 로그에 자동으로 붙게 하는 기능이다. 멀티스레드 환경에서 요청별 로그를 묶어 추적할 때 쓴다.

## Evidence

- 사용: `MDC.put("requestId", "12345"); log.info("Message");` 후 Logback 패턴에서 `%X{requestId}`로 출력하거나 JSON 인코더로 필드화한다.
- 보통 HTTP 요청 필터에서 넣고 요청이 끝나면 지운다. 서블릿 필터가 없는 gRPC·소켓 기반 서버에서는 메시지 핸들러 진입 직후에 직접 넣는다.
- MDC는 스레드 로컬이므로 스레드 풀에서 재사용될 때 이전 값이 남지 않게 처리 후 `MDC.clear()`해야 한다. 비동기로 다른 스레드에 작업을 넘기면 문맥을 복사해 전달해야 한다(일반 지식).
- 콜 처리 시스템에서는 원콜 ID, 미디어 세션 ID, 메시지 ID처럼 흐름 전체를 관통하는 키를 넣어 grep 한 번으로 호 시작부터 종료까지 추적할 수 있다.
