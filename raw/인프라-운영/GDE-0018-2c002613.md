# Nginx 를 헬스체크 모듈과 함께 소스 빌드하는 Dockerfile

## Purpose

업스트림 능동 헬스체크가 필요한데 배포판 Nginx 패키지에 모듈이 없을 때, 서드파티 모듈을 넣어 Nginx 를 소스 빌드하는 컨테이너 이미지를 만든다.

## Steps

1. 베이스 이미지에 TZ, 빌드 도구(gcc, make, wget, unzip), openssl·pcre·zlib 개발 패키지, logrotate, cronie 를 설치한다.
2. Nginx 소스와 upstream check 모듈 소스를 내려받아 푼다.
3. `./configure --with-http_realip_module --with-stream --add-module=<모듈 경로>` 후 make, make install 한다.
4. 같은 RUN 단계에서 소스·압축 파일과 빌드 도구를 지우고 패키지 캐시를 비워 이미지 크기를 줄인다.
5. 비 root 실행 사용자를 만들고 Nginx temp·log 디렉토리 소유권을 넘긴다.
6. logrotate 설정을 복사하고 `sed -i 's/\r//'` 로 CRLF 를 제거한다(Windows 에서 작성한 파일 대비).
7. 사용자 crontab 에 logrotate 를 등록한다.
8. `USER` 로 비 root 사용자를 지정하고, ENTRYPOINT 는 권한 보정 스크립트, CMD 는 `nginx -g 'daemon off;'` 로 둔다.
