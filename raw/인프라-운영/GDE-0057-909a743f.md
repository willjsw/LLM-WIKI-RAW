# Jenkins REST API로 Job 설정 XML을 멱등 등록하는 스크립트

## Purpose

저장소에 둔 Jenkins Job 설정 XML들을 정해진 순서로 Jenkins에 등록하되, 있으면 갱신하고 없으면 생성해 여러 번 실행해도 결과가 같게 한다.

## Steps

1. Jenkins 사용자 설정에서 API 토큰을 발급한다. URL, 사용자, 토큰은 환경변수로 받고 `${VAR:?메시지}`로 누락 시 바로 종료한다.
2. `--dry-run` 인자면 생성/갱신 여부만 출력한다.
3. `curl -fsS -u "$USER:$TOKEN" "$JENKINS_URL/whoAmI/api/json"`로 인증을 먼저 확인한다.
4. `crumbIssuer/api/xml?xpath=concat(//crumbRequestField,":",//crumb)`로 CSRF crumb을 받고 `tr -d '\r\n'`로 개행을 지운다. 결과가 `이름-Crumb:값` 형식이 아니면 빈 값으로 두고 쓰지 않는다.
5. 등록 순서 배열을 하위 Job(빌드 → 이미지 전송 → 배포) → 모듈 오케스트레이터 → 전체 마스터 순으로 둔다. 상위 Job이 하위 Job을 참조하기 때문이다.
6. Job마다 `GET /job/<name>/api/json`이 200이면 `POST /job/<name>/config.xml`로 갱신, 아니면 `POST /createItem?name=<name>`으로 생성한다. `Content-Type: application/xml`, `--data-binary @<file>`, crumb 헤더는 `${CRUMB:+-H "$CRUMB"}`로 있을 때만 붙인다.
7. 응답 코드가 200이 아니면 응답 본문에서 title, Caused by, 예외 클래스 줄만 골라 출력하고 전체 응답은 파일로 저장한다.
8. 끝나면 `api/json?tree=jobs[name]`으로 등록 목록을 확인한다.
