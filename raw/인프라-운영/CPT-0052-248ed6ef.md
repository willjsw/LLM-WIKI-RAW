# 티어링 KV Cache와 노드 간 캐시 공유

## Definition

티어링 KV Cache는 KV Cache를 GPU 메모리 → CPU 메모리 → 외부 스토어로 계층화해 히트율을 확보하고, 외부 스토어를 통해 다른 노드가 만든 캐시도 복원해 재사용하는 구조다.

## Evidence

- 해결하려는 문제: 캐시량이 끝없이 늘고, 캐시가 파드/노드에 갇혀 공유되지 않는다
- LMCache 같은 캐시 레이어가 외부 키-값 스토어(ElastiCache/Valkey)에 캐시를 저장·복원한다
- 수십 GB급 대형 캐시 복원 최적화가 실전 과제다
- 운영에는 LLM, 서빙 엔진, 분산 캐시 지식이 모두 필요하므로 관리형 오퍼레이터로 위임하는 선택지가 있다
