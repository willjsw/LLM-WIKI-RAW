# Rocky Linux 9 GUI 설치와 Non-RAID 디스크 파티션 구성

## Purpose

RAID 컨트롤러가 있는 서버에 RAID를 쓰지 않고 디스크 두 개를 묶어 Rocky Linux 9(GUI)를 설치하고 데이터용 파티션을 따로 확보한다.

## Steps

1. Rocky 공식 ISO(dvd 또는 minimal)를 Rufus나 BalenaEtcher로 8GB 이상 USB에 쓴다.
2. RAID 컨트롤러가 있으면 부팅 시 컨트롤러 설정 화면(Dell PERC는 Ctrl+R)에서 각 디스크를 Convert to Non-RAID로 바꾸고 재부팅한다.
3. 부팅 장치 선택 키로 USB 부팅 후 'Install Rocky Linux 9.x'를 고른다.
4. 언어와 시간대(아시아/서울)를 설정한다.
5. 소프트웨어 선택에서 '서버 - GUI 사용'을 고른다.
6. 설치 목적지에서 두 디스크를 모두 체크하고 저장소 구성을 '사용자 정의'로 둔다.
7. 수동 파티션 화면에서 자동 생성 링크를 눌러 기본 레이아웃(/boot, swap, /, /home)을 만든 뒤 /home을 50GiB로 줄인다.
8. + 버튼으로 /data 마운트 지점을 남은 용량(예: 400GiB)으로 추가하고 변경 사항을 적용한다.
9. root 비밀번호와 일반 사용자를 만든다.
10. 네트워크와 호스트 이름에서 이더넷을 켠다(설치 후 `nmtui`로도 가능).
11. 설치 후 `nmcli -f NAME,AUTOCONNECT connection show`로 이더넷 자동 연결 여부를 확인하고, 꺼져 있으면 `nmcli connection modify <연결명> connection.autoconnect yes`로 켠다.
12. 설치를 시작하고 완료되면 USB를 뺀 뒤 재부팅한다.
