# chmod 숫자 모드와 기호 모드

## Definition

chmod 는 파일의 읽기(r)·쓰기(w)·실행(x) 권한을 소유자·그룹·기타 사용자별로 바꾸는 명령이다. 숫자 모드는 r=4, w=2, x=1 을 합산하고, 기호 모드는 대상(u/g/o/a)과 연산(+, -, =)으로 표현한다.

## Evidence

- `chmod 755 script.sh`: 소유자 7(rwx), 그룹 5(r-x), 기타 5(r-x). 쉘 스크립트·웹 서버 파일의 표준 권한이다.
- `chmod u+x script.sh` 는 소유자에 실행 권한을 더하고, `chmod o-w index.html` 은 기타 사용자의 쓰기 권한을 뺀다.
- 권한 변경은 파일 소유자와 root 만 할 수 있다. 그룹 구성원은 바꿀 수 없다.
- `-R` 로 하위 디렉토리까지 재귀 적용한다.
- 권한·소유자 정보는 inode 에 들어 있고, chmod·chown 은 그 inode 필드를 수정한다. 소유자·그룹 변경은 `chown 사용자:그룹 파일`(`-R` 재귀, `-v` 변경 내역 출력)로 한다.
