# 통계 Backbone과 LLM 해석의 하이브리드 이상 탐지

## Definition

운영 이상 탐지에서 수치 판단은 통계·ML 모델(Backbone)이 맡고, LLM은 그 결과를 자연어로 해석하고 여러 영역의 판단을 종합한다. 이상을 알아차리는 것은 정상을 얼마나 잘 정의하느냐의 문제이므로 통계적 기반이 먼저 필요하다.

## Evidence

- 지표 특성별로 모델을 고른다: 동시접속자는 시계열 분해, 변화가 적은 지표는 확률 변환과 랭킹, 시스템 메트릭은 동질 서버 대비 종합 이상탐지와 랭킹
- 과거 장애 이력 기반으로 관련 지표를 찾고, 지표 간 관계로 다변량 이상치를 찾는다
- 도메인별 전문가 에이전트가 각자 영역을 분석·보고하고 리드 에이전트가 하나의 판단으로 통합한다
- 파이프라인: 매일 학습 → 매분 추론 → 이상 감지 시 종합 추론
- 발표 사례 성과: 탐지~원인 파악 30분에서 1분 이내, 불필요 알림 1/3 필터링(발표 기준 수치)
