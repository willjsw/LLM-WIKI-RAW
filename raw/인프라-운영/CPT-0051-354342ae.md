# LLM 추론의 Prefill-Decode 단계와 KV Cache

## Definition

LLM 추론은 프롬프트 전체를 병렬 처리해 KV Cache를 만드는 Prefill 단계와, 캐시를 읽으며 토큰을 하나씩 생성하고 그 KV를 캐시에 추가하는 Decode 단계로 나뉜다. KV Cache가 이전 토큰의 Key/Value 재계산을 없애므로 서빙 성능의 핵심이 된다.

## Evidence

- 캐시가 없으면 토큰마다 이전 문장 전체를 다시 계산해야 한다
- 캐시 룩업으로 이전 컨텍스트와 같은 부분은 재사용하고 사용자 프롬프트 증분만 새로 처리한다
- GPU 메모리는 모델 가중치뿐 아니라 KV Cache도 점유한다
- vLLM, SGLang 등 주요 서빙 엔진에 기본 내장되어 있다
- 그 밖의 서빙 과제: Cold Start 방지, GPU 리소스 관리, 리전 용량 부족 시 멀티 클러스터/리전 활용
