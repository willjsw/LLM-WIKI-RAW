# 절체 재처리 이벤트의 멱등성 조건

## Definition

절체 후 이벤트를 다시 발행하거나 큐에 다시 넣으려면 연관 서비스가 '같은 이벤트를 한 번 더 처리할 수 있는가'와 '한 번 더 처리해도 문제가 없는가'를 모두 만족해야 한다.

## Evidence

- 라우팅 서버는 Active-Standby 간 요청 정보가 동기화돼 있다는 전제에서, 절체 시 대기 큐 데이터를 재투입(Re-queue)한다.
- 동일 요청이 2번 들어오는 경우를 위한 중복 체크 로직이 필요하다.
- 절체 순간 요청 측(시나리오 매니저)에서 타임아웃이 나는 경우도 처리해야 한다.
- 재투입은 고객 이탈을 막지만 통계 중복을 만들 수 있어 사후 보정이 병행돼야 한다.
