# 리눅스 사용자 계정 파일과 UID

## Definition

리눅스 커널은 사용자와 그룹을 이름이 아니라 UID/GID 숫자로 판별한다. 계정 정보는 /etc/passwd, 비밀번호 해시는 /etc/shadow, 그룹 정보는 /etc/group 에 저장된다.

## Evidence

- `/etc/passwd`: 사용자 목록, UID, 주 그룹, 홈 경로, 로그인 쉘을 평문으로 기록한다.
- `/etc/shadow`: 해시된 비밀번호. root 만 읽을 수 있다.
- `/etc/group`: 그룹과 소속 사용자.
- 숫자로 판별하므로 여러 서버가 같은 파일을 공유(NFS)하거나 HA 클러스터를 이룰 때 같은 계정의 UID 를 맞추지 않으면 권한이 어긋난다.
