# Docker 이미지 레이어 생성 규칙과 whiteout

## Definition

Docker 이미지는 Dockerfile 명령 단위로 쌓인 레이어로 구성되며, 실제 파일시스템 레이어는 RUN·COPY·ADD 만 만든다. 각 레이어는 직전 상태와의 차이만 기록하므로 위 레이어에서 파일을 지워도 아래 레이어의 용량은 그대로 남는다.

## Evidence

- FROM, ENV, WORKDIR, CMD, ENTRYPOINT, EXPOSE, LABEL, ARG, USER, VOLUME 은 히스토리에 한 단계로 남지만 거의 0바이트다.
- 예: `RUN wget big.tar.gz`(100MB) → `RUN tar -xf` → `RUN rm big.tar.gz` 로 나누면 마지막 레이어는 삭제 표시(whiteout)만 하고 100MB 는 첫 레이어에 남는다.
- `docker history <image>` 로 각 명령이 만든 레이어와 크기를 최신→과거 순으로 확인해 용량이 튀는 단계를 찾는다.
