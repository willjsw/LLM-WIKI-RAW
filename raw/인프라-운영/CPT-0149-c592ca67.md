# 파괴적 API 의 명시적 confirm 파라미터

## Definition

전체 종료·일괄 삭제처럼 되돌리기 어려운 작업을 하는 API 는 `confirm=true` 같은 명시적 확인 파라미터가 없으면 아무것도 하지 않고 오류를 돌려주게 설계한다.

## Evidence

- 잘못된 스크립트나 실수로 호출해도 실제 동작이 일어나지 않는다.
- 확인 누락은 전용 오류 코드로 구분해 호출자가 원인을 바로 알 수 있게 한다.
- 정상 접수 응답에는 "이 응답 직후 종료된다"처럼 이후 일어날 일을 명시한다.
