# JWT 서명키 무중단 전환 절차

## Purpose

기존 서명키에서 새 서명키(새 키 저장소)로 서비스 중단 없이 옮긴다.

## Steps

1. JWT 헤더에 kid를 넣어 어떤 키로 서명했는지 식별할 수 있게 한다
2. 검증 측이 동적으로 읽는 설정(Dynamic Config)에 신규 공개키를 등록한다. 검증은 kid로 공개키를 찾으므로 여러 키가 공존해도 안전하다
3. 서명 비율을 기존 키에서 신규 키로 점진적으로 옮기며 에러율과 레이턴시를 모니터링한다
4. 기존 키 서명을 중단한다. 이미 발급된 토큰은 클라이언트에 남아 있으므로 TTL이 소진될 때까지 기다린다
5. 기존 토큰이 100% 만료된 뒤 설정에서 기존 공개키를 삭제한다
