# 하네스 엔지니어링과 에이전트 가드레일

## Definition

하네스 엔지니어링은 프롬프트·컨텍스트 엔지니어링을 넘어 에이전트의 권한, 실행 범위, 승인 절차 같은 통제 구조 자체를 설계하는 단계다. 가드레일은 그 통제 구조 안에서 에이전트 행동 범위를 제한하는 장치다.

## Evidence

- 진화: 프롬프트 엔지니어링 → 컨텍스트 엔지니어링 → 하네스 엔지니어링
- 가드레일 예: 전역 규칙(어떤 요청이든 명시된 규칙 안에서만 행동), 실행 권한(Action/Skill 단위), 연동 범위(MCP 서버 단위 토글), IP 화이트리스트
- 실행 전 Human-in-the-Loop 점검과 Step별 입출력 원문 기록을 둔다
- 역할 분리 체이닝: 기획 에이전트 → 실행 에이전트 → 평가 에이전트(Pass/Fail)
- 에이전트 구성 프레임 예: Trigger → Context → AI → Action → Guardrail → Output
