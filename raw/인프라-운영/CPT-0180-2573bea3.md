# 결정론적 암호화와 확률적 암호화

## Definition

결정론적 암호화는 같은 평문과 키에 대해 항상 같은 암호문을 만들고, 확률적 암호화는 IV나 salt를 써서 매번 다른 암호문을 만든다. 확률적 방식이 기본 원칙이지만, 결정론적 방식은 암호문끼리 같음 비교로 검색할 수 있어 조회 성능이 좋다.

## Evidence

- 결정론적: 조회 시 검색어를 같은 방식으로 암호화해 DB 암호문 문자열과 비교하면 된다. 대신 같은 값의 빈도가 드러난다.
- 확률적: 조회할 때마다 후보를 복호화해야 하므로 검색 비용이 크다.
- 전화번호 검색, 통화 ID 조회처럼 조회 빈도가 높은 컬럼에서 화면 성능 때문에 결정론적 방식을 원하는 요구가 나왔다.
- 대안으로 컬럼은 확률적으로 암호화하고 검색용 키 해시(블라인드 인덱스) 컬럼을 따로 두는 방식도 검토할 수 있다(일반 기법, 원문 미기재).
