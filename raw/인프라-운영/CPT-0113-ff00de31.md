# docker exec 와 docker attach 의 차이

## Definition

docker exec 는 실행 중인 컨테이너 안에 새 프로세스를 띄워 명령을 실행하고, docker attach 는 컨테이너의 PID 1 프로세스 입출력에 직접 붙는다.

## Evidence

- `docker exec <c> ls` 는 결과만 호스트에 출력하고 끝난다. `docker exec -it <c> /bin/bash` 는 새 쉘을 띄우며, 그 쉘을 나가도 컨테이너는 계속 돈다.
- attach 로 붙은 상태에서 쉘을 종료하면 PID 1 이 끝나므로 컨테이너도 종료된다. 컨테이너를 살려 둔 채 떼려면 Ctrl+P, Ctrl+Q 를 누른다.
- attach 는 PID 1 의 실시간 출력(로그) 모니터링에 쓴다.
- `-i` 는 표준입력 유지, `-t` 는 TTY 할당으로 보통 같이 쓰고, `-d` 는 백그라운드 실행이다.
