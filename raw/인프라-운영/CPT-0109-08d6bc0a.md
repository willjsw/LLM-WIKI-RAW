# 리눅스 표준 디렉토리 구조

## Definition

리눅스 루트(/) 아래 디렉토리는 용도별로 나뉜다. 설정은 /etc, 가변 데이터와 로그는 /var, 실행 중 프로세스·커널 상태는 메모리 기반 가상 파일시스템 /proc 에 있다.

## Evidence

- `/bin` 누구나 쓰는 기본 명령(ls, cp), `/sbin` 관리자용 시스템·네트워크 명령(fdisk, reboot, iptables).
- `/home/<user>` 일반 사용자 홈, `/root` 는 root 전용 홈으로 `/` 와 별개다.
- `/tmp` 는 누구나 쓰는 임시 공간이고 재부팅 시 보통 비워진다.
- `/usr` 는 필수가 아닌 패키지·라이브러리 공간으로 루트 구조(bin, sbin, lib, share, include)를 축소 복제한다. `/usr/local` 은 패키지 관리자를 거치지 않고 소스를 직접 컴파일해 설치한 소프트웨어 자리다.
- `/opt` 는 서드파티 상용 패키지, `/dev` 는 장치 파일(장치도 파일로 다룬다), `/boot` 는 커널 이미지와 부트로더 설정이다.
- `/media` 는 OS 가 자동 관리하는 이동식 매체, `/mnt` 는 사용자가 명령으로 직접 마운트할 때 쓴다.
- 데몬 장애 확인은 `/var/log`, 서비스 설정 수정은 `/etc` 에서 한다.
