# Docker 볼륨 마운트 UID GID 불일치 문제

## Definition

bind mount 한 호스트 디렉토리의 파일 권한은 숫자 UID/GID 로 판정되므로, 이미지 빌드 시점에 만든 컨테이너 사용자 UID 와 호스트에서 디렉토리를 소유한 UID 가 다르면 컨테이너 프로세스가 로그·설정 파일에 접근하지 못한다.

## Evidence

- 기본 UID 1000 을 하드코딩하면 서버마다 계정 UID 가 달라 접근이 실패한다.
- 해결 방향은 세 가지가 논의됐다: 빌드 인자로 UID 지정, compose 실행 시 UID/GID 주입, 엔트리포인트에서 실행 UID 에 맞춰 계정 정보를 고치는 방식.
- Dockerfile 에서 UID 변수 이름을 UID 로 두면 셸 내장 변수와 충돌하므로 APP_UID 처럼 다른 이름을 쓴다.
