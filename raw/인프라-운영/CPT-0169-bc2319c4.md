# CloudWatch 기본 EC2 지표에는 OS 메모리가 없다

## Definition

CloudWatch 가 EC2 에 대해 기본 제공하는 지표는 인스턴스를 호스팅하는 하이퍼바이저 쪽에서 보이는 값(CPU 등)이며, 메모리 사용량처럼 OS 내부에서만 알 수 있는 지표는 포함되지 않는다. OS 지표를 보려면 인스턴스에 CloudWatch Agent(또는 다른 에이전트)를 설치해야 한다.

## Evidence

- 파트너 미팅에서 자사 에이전트형 모니터링 도구의 필요성을 설명하며 나온 내용으로, CloudWatch Agent 를 설치하면 CloudWatch 로도 OS 지표를 볼 수 있다는 점이 함께 확인됐다. 별도 도구를 고르기 전에 CloudWatch Agent 로 충분한지 먼저 따져 볼 근거다.
- RDS·Lambda·ElastiCache 같은 매니지드 서비스에는 에이전트를 설치할 수 없다. 외부 모니터링 도구는 IAM 자격 증명으로 CloudWatch API 를 호출해 지표를 끌어오며, 이 API 호출량에 따라 추가 비용이 생길 수 있다.
- 최신 지표 범위와 요금은 AWS 공식 문서로 다시 확인해야 한다.
