# 가변 작업 공간과 불변 확정 스냅샷의 도메인 분리

## Definition

사람들이 계속 고치는 가변 작업 공간과, 특정 시점의 결과를 복사해 만든 불변 확정본을 별도 엔티티로 나누는 설계다. 작업 공간의 이후 변경이 이미 만든 확정본으로 전이되지 않는다.

## Evidence

- 작업 공간의 lock은 다른 도메인 부수효과가 아니라 '수정 금지 플래그' 하나의 의미로 둔다. 잠금 후에는 항목 선택 토글도 금지한다.
- 확정본 생성 조건: 잠금 상태일 것, 선택된 항목만 대상, 선택 항목이 없으면 비즈니스 예외.
- 작업 공간 엔티티를 확정본 엔티티로 1:1 매핑해 복사하고, 교차 도메인 생성은 Facade 한 곳에서 트랜잭션으로 처리한다.
- 확정 조건은 '확정 레코드가 존재하는가'가 아니라 '세션마다 확정 수가 필요 인원과 같은가'처럼 정확히 정의한다.
- 확정 대상은 확정된 참여자만이며 미확정 지원자는 스냅샷에 넣지 않는다.
