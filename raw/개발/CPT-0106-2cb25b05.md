# MCP 서버 instructions 는 짧은 연결 안내로만 쓴다

## Definition

MCP 서버는 initialize 응답에 instructions 를 줄 수 있고 Claude Code 는 이를 모델 시스템 프롬프트에 넣는다. 사용자가 Prompt 를 고르지 않은 자연어 요청에서도 특정 리소스·형식을 쓰게 하려면 instructions 에 '이럴 때 이 리소스를 읽어라' 같은 연결 고리만 둔다.

## Evidence

- 매 세션 컨텍스트를 쓰므로 짧게 쓰고, 긴 내용은 Resource 로 뺀다.
- 접속한 모든 클라이언트·모델에 노출되므로 비밀값·내부 주소를 넣지 않는다.
- 접속 시 한 번 전달되므로 바꾸면 클라이언트가 재연결해야 한다.
- 강제력이 없다. 출력 형식을 확실히 고정하려면 Prompt 를 쓴다.
- instructions 가 가리키는 리소스 URI 가 실제로 등록돼 있는지, 리소스와 프롬프트가 같은 원문을 쓰는지 테스트로 검사해 두면 어긋남을 막을 수 있다.
