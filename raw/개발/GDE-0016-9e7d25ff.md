# GC 로그 수집 옵션 설정(Java 8 계열)

## Purpose

GC 동작을 파일로 남겨 정지 시간·빈도·누수 패턴을 사후 분석할 수 있게 한다.

## Steps

1. `-verbose:gc`로 GC 이벤트 기본 정보를 출력한다
2. `-XX:+PrintGCDetails`로 이벤트별 상세 정보를, `-XX:+PrintGCDateStamps`로 날짜 스탬프를 남긴다
3. `-Xloggc:<파일경로>`로 GC 로그를 별도 파일로 보낸다
4. `-XX:+UseGCLogFileRotation`, `-XX:NumberOfGCLogFiles=<개수>`, `-XX:GCLogFileSize=<크기>`로 로그 로테이션을 설정해 디스크를 보호한다
5. 수집한 로그는 GC 로그 분석 도구로 열어 Full GC 직후 최저점 추이와 정지 시간을 확인한다
6. Java 9 이상은 통합 로깅(`-Xlog:gc*`)으로 옵션 체계가 바뀌었으므로 버전에 맞게 바꾼다(추가 확인 필요)
