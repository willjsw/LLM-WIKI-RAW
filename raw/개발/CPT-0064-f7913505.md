# JVM 옵션 체계와 Ergonomics 플래그 읽기

## Definition

JVM 옵션은 모든 JVM에 공통인 Standard 옵션과 버전별로 다른 Non-standard 옵션(-X는 거시 제어, -XX는 미시 제어)으로 나뉜다. Java 5부터는 Ergonomics가 하드웨어·OS 정보를 기준으로 GC와 Heap 크기를 자동 선택한다.

## Evidence

- -XX 형태: Boolean `-XX:+옵션`/`-XX:-옵션`, Numeric `-XX:옵션=값`(k/m/g 단위, 단위가 없으면 byte), String `-XX:옵션=문자열`
- `-XX:+PrintFlagsFinal` 출력에서 `=`는 디폴트 그대로, `:=`는 Ergonomics나 명령행으로 바뀐 값이다
- `{manageable}` 플래그는 운영 중 JMX 등으로 동적 변경이 가능하다. `HeapDumpOnOutOfMemoryError`, `HeapDumpPath`가 여기에 속해 재기동 없이 OOM 시 자동 덤프를 켤 수 있다
- `-XX:+PrintCommandLineFlags`로 Ergonomics가 고른 값(초기·최대 Heap, GC)을 확인한다
- 자주 쓰는 -X 옵션: `-Xms`/`-Xmx`(Heap 초기·최대), `-Xss`(스레드 스택), `-Xint`(인터프리터 전용), `-Xloggc`
- `-verbose:class|gc|jni`는 트러블슈팅의 1차 도구, `-javaagent`(Java 5+)는 APM 에이전트 부착에 쓰인다
- `java.class.version` 52는 Java 8이다
