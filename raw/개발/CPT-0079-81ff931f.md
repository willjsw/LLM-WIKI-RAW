# Java Flight Recorder(JFR)의 이벤트 기록 방식

## Definition

JFR은 실행 중인 JVM의 이벤트를 운영 부하를 거의 주지 않고 기록하는 진단·프로파일링 도구다. 이벤트는 이름, 발생 시각, payload(전후 CPU 사용량, Heap 크기, Lock Holder 스레드 ID, 지속 시간, 스택 트레이스)로 구성된다.

## Evidence

- 이벤트 종류: instant(발생 즉시 기록), duration(시작·종료, 종료 시 기록), timed(임계값 이상 지속된 것만 기록), sample(일정 간격 수집)
- jcmd 명령: `JFR.start`, `JFR.check`, `JFR.stop`, `JFR.dump`
- 기록 분석은 JMC에서 한다
- 라이선스 주의: 강의 기준 Oracle JDK 구버전에서는 운영 사용 시 상용 라이선스가 필요하며, 상용 기능을 unlock하는 행위 자체가 사용에 해당한다(사용 중인 JDK 배포판별 확인 필요)
