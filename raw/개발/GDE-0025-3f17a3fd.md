# AI 에이전트 작업의 이슈-커밋-PR 운영 흐름

## Purpose

작업 관리 도구의 태스크를 AI 에이전트가 수행할 때 GitHub 이슈·커밋·PR 로 추적되게 한다.

## Steps

1. 태스크 실행 지시를 받으면 먼저 이슈 컨벤션에 맞춰 원격 저장소에 이슈를 등록한다.
2. 별도 지시가 없으면 정해 둔 GitHub Project 에 이슈를 연결한다. 프로젝트 이름·번호처럼 불확실한 값은 `gh` 로 조회해 확인한 뒤 문서에 적는다.
3. 태스크를 끝낼 때마다 그 단위로 커밋한다.
4. PR 지시를 받으면 PR 컨벤션대로 작성하고 assignee, label, milestone 을 채운 뒤 Squash and Merge 한다.
5. 병합 중 충돌·오류가 나면 임의로 해결하지 말고 내용을 보고하고 해결 방안을 제시한다.
