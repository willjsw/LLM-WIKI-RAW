# 결정론 암호화의 salt·nonce 유도와 길이 프리픽스

## Definition

결정론 암호화는 salt 와 nonce 를 랜덤 대신 평문과 AAD 의 HMAC 으로 유도해 같은 입력에서 항상 같은 암호문을 만든다. 입력을 이어 붙일 때는 각 부분 앞에 길이를 붙여야 서로 다른 조합이 같은 입력으로 해석되지 않는다.

## Evidence

- 유도 예: `K_det = HKDF(master, salt=0x00*32, info=<결정론 전용 문자열>)`, `S = HMAC-SHA256(K_det, BE32(len(pt)) ‖ pt ‖ BE32(len(aad)) ‖ aad)`, salt = S[0..15], nonce = S[16..27].
- 길이 프리픽스가 없으면 (pt="ab", aad="c") 와 (pt="a", aad="bc") 가 같은 바이트열이 되어 같은 salt·nonce 를 받는다.
- RFC 5869 의 "salt 미지정"은 해시 길이만큼의 0 바이트와 같다. JCE 는 빈 HMAC 키를 거부하므로 0 바이트 32개로 표기한다.
- 결정론 모드는 마스터키 유도 모드에서만 허용하고, 원시키 모드와 혼용하면 거부한다.
