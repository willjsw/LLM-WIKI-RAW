# 코드가 좁히고 LLM 이 판단한다

## Definition

LLM 파이프라인에서 결과가 확실한 기계적 처리(정제, 그룹핑, 마스킹)는 결정론적 코드에 맡기고, 의미 판단이 필요한 일(무엇이 중요한가, 주제가 몇 개인가)만 LLM 에 맡기는 설계 원칙이다.

## Evidence

작업 로그로 기술 블로그 초안을 만드는 파이프라인에서 1단계 스크립트가 로그 정제·브랜치 그룹핑·식별자 마스킹을 하고, 2단계 LLM 스킬이 글감을 판단하고, 3단계 LLM 스킬이 초안을 쓴다. 각 경계에서 지켜야 할 규칙을 문서로 남긴다. 마스킹처럼 빠지면 안 되는 처리를 코드로 두면 LLM 이 놓치는 위험이 줄고, LLM 에 넘기는 입력도 작아진다.
