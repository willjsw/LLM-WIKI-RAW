# github-label-sync 로 저장소 라벨 표준화

## Purpose

여러 저장소에 같은 이슈·PR 라벨 체계를 코드로 정의하고 동기화한다.

## Steps

1. labels.json 에 라벨 목록을 `{name, description, color}` 배열로 정의한다. 예: feature(기능 추가), chore(CI/CD·설정), ai(AI 자동화 작업), refactor, bug/error, test, style(코드 스타일·포맷), design(UI).
2. `npm install -g github-label-sync` 로 도구를 설치한다.
3. 토큰은 `GITHUB_TOKEN` 환경변수로만 넘긴다. 문서·저장소에 평문으로 남기지 않는다.
4. `github-label-sync --access-token $GITHUB_TOKEN --labels labels.json <owner>/<repo>` 로 동기화한다. 정의에 없는 기존 라벨은 지워질 수 있으니 먼저 현재 라벨을 확인한다.
5. 확인: `curl -H "Authorization: token $GITHUB_TOKEN" https://api.github.com/repos/<owner>/<repo>/labels`.
6. 토큰이 노출되면 GitHub Settings → Developer settings → Personal access tokens 에서 즉시 revoke 하고 새로 발급한다.
