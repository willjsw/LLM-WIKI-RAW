# 함수 포인터 기반 유한 상태 머신

## Definition

함수 포인터 테이블로 "현재 상태에서 이 이벤트가 오면 실행할 함수"를 지정해, 조건 분기 없이 상태에 따라 동작을 바꾸는 유한 상태 머신 구현 방식이다.

## Evidence

- 상태마다 다음에 수행할 함수를 포인터로 연결해 두면 상위 if/switch 없이 전이가 일어난다.
- 전화 교환기의 호 처리처럼 상태가 많고 이벤트가 비동기로 오는 시스템에서 쓴다.
- 함수 포인터는 실행 파일에 저장된 함수의 주소를 담는 변수다.
