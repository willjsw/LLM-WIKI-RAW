# MCP(Model Context Protocol)의 역할

## Definition

MCP는 에이전트와 도구·데이터 소스를 연결하는 표준 인터페이스로, 도구 목록과 각 파라미터의 의미를 함께 에이전트에 전달한다. 기존 애플리케이션에 MCP 레이어만 추가하면 에이전트가 쓸 수 있는 에이전틱 애플리케이션이 된다.

## Evidence

- 흐름: MCP 서버 연결 → MCP 클라이언트가 도구 목록 획득 → 에이전트가 도구 호출
- 서버 측은 `@server.list_tools()` 같은 어노테이션 방식으로 간단히 구축할 수 있다
- 도구 설계는 조회·SQL·범용 변경 도구를 데이터 사용자 관점에서 고른다
- 도구 연결을 넘어 데이터 거버넌스, 보안 통제(서버 단위 연동 범위 토글), 실시간 컨텍스트 제공 단위로 쓰임이 넓어지고 있다
- 상호 운용성 축은 MCP(도구) + Agent Skills + A2A(에이전트 간 통신)로 정리된다
