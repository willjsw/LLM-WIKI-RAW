# SysV 공유 메모리의 프로세스 수명 독립성

## Definition

System V 공유 메모리 세그먼트는 키로 생성되어 커널에 남고, 만든 프로세스가 종료돼도 명시적으로 제거하기 전까지 데이터가 유지된다. 다른 프로세스는 같은 키로 attach해 같은 메모리를 읽고 쓴다. malloc 메모리가 프로세스 종료와 함께 사라지는 것과 다르다.

## Evidence

- 교환기 구조: 기동 시 생성 프로세스가 공유 메모리 세그먼트(제어 영역 + 자원 구조체 배열 + 해시)를 만들고, LOAD 명령으로 DB 데이터를 메모리에 올린다.
- 관리 명령어는 각각 독립 실행 파일이며 실행될 때마다 같은 키로 attach해 풀을 순회한다. 중앙 디스패처가 없다.
- 쓰기 명령은 공유 메모리와 DB를 둘 다 갱신해야 일관성이 유지된다.
- 구조체 배열의 시작 주소를 가리키는 포인터로 세그먼트를 다룬다.
- 이중화 시 공유 메모리 내용은 다른 서버로 자동 복제되지 않으므로 별도 동기화가 필요하다.
