# 공유 슬롯과 배타 슬롯 실행 모델에서 409 와 좀비의 영향

## Definition

정기 실행은 공유 슬롯(동시 진입 허용), 복구·수동 실행처럼 프로세스 전역 상태를 바꾸는 모드는 배타 슬롯(단독 실행)으로 나누고, 대기 없이 진입이 안 되면 즉시 409 를 돌려주는 실행 모델이다.

## Evidence

- 공유 진입 조건: 배타 대기자가 없고, 실행 중인 것이 없거나 모두 공유 모드일 때. 배타 대기자가 있으면 새 공유 요청도 409 로 막아 배타 요청의 기아를 막는다.
- 배타 진입 조건: 실행 중인 것이 하나도 없을 때.
- 배타 모드가 프로세스 전역 환경변수를 바꾸기 때문에 섞이면 안 된다.
- 실무 함의: 정기 실행끼리는 앞 실행이 늘어져도 서로 막지 않는다. 막히는 것은 복구 실행뿐이다. 그래서 좀비 실행의 실질 피해는 '정기 실행 연쇄 실패'가 아니라 '복구 경로 봉쇄'이고, 부분 처리 상태가 해소되지 않고 쌓인다.
- 409 는 다음 주기에 자연 해소되는 일시적 오류로 보고 재시도 대상에 둔다.
