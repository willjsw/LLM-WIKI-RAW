# 브라우저 WebSocket 인증 정보는 STOMP CONNECT 헤더로 전달

## Definition

브라우저 `new WebSocket(url, protocols)` 는 업그레이드 HTTP 요청에 임의 헤더를 실을 수 없으므로, 인증 정보는 STOMP CONNECT 프레임 헤더에 싣는다. 공개 웹페이지에 들어가는 키는 비밀이 아니므로 실제 방어는 Origin 허용 목록과 유량 제한이 맡는다.

## Evidence

- 업그레이드 요청에는 브라우저가 `Origin`·쿠키만 자동으로 붙인다.
- CONNECT 프레임 헤더에는 무엇이든 실을 수 있어, 서버 `ChannelInterceptor` 가 CONNECT 에서 키를 검사하고 실패 시 ERROR 를 보낸다.
- Origin 검사는 업그레이드 단계(403)와 CONNECT 단계(ERROR) 중 어디서 할지 명세에 정해야 한다. 클라이언트가 받는 신호가 다르다.
- 서버 내부 매체(Redis 등) 장애가 연결 수립 실패로 번지지 않도록, 연결 서버가 혼자 계산할 수 있는 식별자 발급은 외부 발행과 묶지 않는다.
