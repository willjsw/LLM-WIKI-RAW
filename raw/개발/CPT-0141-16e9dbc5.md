# 컨텍스트 풀로 동적 할당 비용과 누수 줄이기

## Definition

요청마다 큰 컨텍스트 구조체를 malloc/free 하지 않고, 기동 시 힙에 일정 개수의 컨텍스트를 미리 할당해 풀로 두고 꺼내 쓰고 반납하는 방식이다.

## Evidence

- 컨텍스트가 크면 malloc 자체가 느리고, 해제를 놓치면 누수가 쌓인다.
- 풀을 쓰면 할당 시간이 일정하고 최대 사용량이 풀 크기로 제한된다.
- 서버 기동 순서: 설정 로드 → 컨텍스트 풀 할당 → 포트 오픈 순으로 준비를 끝낸 뒤 요청을 받는다.
- 공유 메모리에 풀을 두면 free/used 연결 리스트(head·tail 인덱스)로 빈 칸과 사용 중 칸을 관리하는 형태가 된다.
