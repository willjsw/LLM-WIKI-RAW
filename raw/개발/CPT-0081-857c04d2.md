# 약한 세대 가설과 Card Table, TLAB

## Definition

약한 세대 가설은 대부분의 객체가 생성 직후 곧 Garbage가 되고(높은 유아 사망률), 오래된 객체가 젊은 객체를 참조하는 일은 드물다는 관찰이다. HotSpot의 Eden/Survivor/Old 구조, Card Table과 Write Barrier가 이 가설 위에 설계되었다.

## Evidence

- 할당 전용 Eden, 복사로 단편화를 해결하는 Survivor, 오래 사는 객체를 따로 관리하는 Old Generation으로 나눈다
- Old→Young 참조는 드물지만 확인은 해야 한다. Old 전체를 훑으면 정지가 길어지므로 Card Table(Old 512바이트당 1바이트 카드)에 Young을 참조하는 Old 객체의 카드를 Dirty로 표시한다
- Write Barrier는 Old→Young 참조가 생길 때 카드를 Dirty로 만드는 원자적 코드로, 네이티브 명령 2개 수준이다
- Bump-the-Pointer는 마지막 할당 위치 바로 뒤에 할당해 빠르지만, 멀티스레드에서는 Heap Lock 경합이 생긴다
- TLAB(Thread Local Allocation Buffer)는 스레드마다 할당 구간을 줘 그 안에서는 동기화 없이 할당하게 한다
