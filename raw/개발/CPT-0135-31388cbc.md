# 프로세스 메모리 영역 Code Data Heap Stack

## Definition

C 프로세스의 메모리는 코드(함수·상수), 데이터(전역·정적 변수), 힙(런타임에 크기가 정해지는 동적 할당), 스택(지역 변수, 함수 종료 시 해제) 영역으로 나뉜다.

## Evidence

- 힙은 malloc/calloc(C), new(C++/Java)로 할당하고, free 하지 않으면 프로그램이 끝날 때까지 남아 누수가 된다.
- 스택 변수는 실행 범위가 끝나면 자동으로 사라지므로 그 주소를 밖으로 돌려주면 안 된다.
- malloc 으로 얻은 메모리는 자기 프로세스 힙이라 다른 프로세스가 볼 수 없다. 프로세스 간 공유에는 공유 메모리 같은 IPC 가 필요하다.
- 포인터가 NULL 이 아닐 때만 free 하고 해제 후 NULL 로 두는 습관이 이중 해제를 줄인다.
