# select 와 poll 입출력 다중화

## Definition

select 와 poll 은 한 프로세스가 여러 파일 디스크립터(FD)를 감시하다가 이벤트가 생긴 FD 만 골라 처리하게 하는 입출력 다중화 함수다.

## Evidence

- FD 0·1·2 는 표준 입력·출력·에러이고, 소켓 등은 그다음 번호부터 순서대로 할당된다.
- select: 감시할 최대 FD+1 과 fd_set(read mask 등)을 넘기고, 돌아오면 모든 FD 를 순회하며 `FD_ISSET` 으로 확인한다. 감시 가능한 FD 수에 상한이 있다.
- poll: 이벤트가 생긴 FD 를 결과 배열에 표시해 주어 FD 가 많을 때 유리하다.
- timeout 0 은 기다리지 않고 바로 반환(폴링), NULL 은 무한 대기다. 주기 타이머와 함께 쓰면 일정 간격으로 깨어나 작업을 처리할 수 있다.
- 연결마다 프로세스를 띄우면 컨텍스트 스위칭 비용 때문에 성능이 오히려 떨어질 수 있다.
