# AI-DLC와 Spec 기반 개발

## Definition

AI-DLC는 AI가 설계·개발을 맡고 사람이 검증·감독·의사결정을 맡는 개발 생애주기 방법론이다. Spec 기반 개발은 모호한 자연어 프롬프트 대신 명세(Spec)로 의도를 고정해 AI 결과의 흔들림을 줄이는 방식이다.

## Evidence

- 원칙: AI 계획 + 인간 검증, AI 실행 + 인간 확인
- 모호한 프롬프트는 모델 결과를 흔들리게 하므로 명세화가 필요하다(예: spec-driven 에이전틱 IDE)
- 개발 라이프사이클의 모든 단계가 동등하게 빨라져야 한다. 코딩만 빨라지면 운영 오버헤드가 병목이 된다
- AI 시대 개발자 자질: 호기심, 오너십, 다방면 지식(T형), 시스템적 사고와 사람–기계 간 명확한 커뮤니케이션
- AI 도입 시 개인 역량 차이가 생산성 차이로 직결되므로 조직 차원의 도입 체계가 필요하다
