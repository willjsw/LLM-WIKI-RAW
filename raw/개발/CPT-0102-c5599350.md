# CAST NULL 빈 뷰로 컬럼 계약을 먼저 제공하기

## Definition

데이터를 채울 파이프라인이 준비되기 전에 `SELECT CAST(NULL AS 타입) AS 컬럼, ...` 만으로 된 뷰를 만들어, 소비 측이 컬럼 이름과 타입(정밀도 포함)을 먼저 받아 개발을 시작할 수 있게 하는 방법이다.

## Evidence

- 각 컬럼을 `CAST(NULL AS NUMERIC(21, 9))`, `CAST(NULL AS VARCHAR(4))` 처럼 최종 타입으로 캐스팅해야 뷰 컬럼 타입이 확정된다. 캐스팅 없이 NULL 만 쓰면 타입이 정해지지 않는다.
- FROM 절 없이 한 행(모두 NULL)을 돌려주므로, 소비 측 쿼리·화면이 오류 없이 돌아가는지 미리 확인할 수 있다.
- 실제 데이터가 준비되면 같은 이름·같은 컬럼 순서·같은 타입으로 `CREATE OR REPLACE VIEW` 해 교체한다. PostgreSQL 의 `CREATE OR REPLACE VIEW` 는 기존 컬럼의 이름·타입·순서를 바꿀 수 없으므로 처음부터 최종 계약대로 만들어야 한다.
- 상담사·큐·VDN 누적 통계, 리소스, 로그인 이력 등 10여 개 뷰를 이 방식으로 먼저 열어 두었다.
