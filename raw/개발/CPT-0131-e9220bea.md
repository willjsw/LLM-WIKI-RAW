# SIP REGISTER 와 다이제스트 인증 흐름

## Definition

SIP REGISTER 는 단말이 자신의 현재 연락 주소(IP·포트)를 등록 서버(교환기)에 저장하는 요청이다. 서버는 처음 요청에 401 Unauthorized 와 인증 챌린지를 돌려주고, 단말이 인증 정보를 실어 다시 보내면 200 OK 로 등록을 확정한다.

## Evidence

- 흐름: 단말 → REGISTER, 서버 → 401(챌린지), 단말 → 인증 정보 포함 REGISTER, 서버 → 200 OK.
- 등록이 되어야 다른 단말의 INVITE 를 교환기가 이 단말의 주소로 라우팅할 수 있다.
- 스택 구현에서는 등록 관련 트랜잭션과 재등록 타이머를 한 스레드에서 관리하는 경우가 많다.
