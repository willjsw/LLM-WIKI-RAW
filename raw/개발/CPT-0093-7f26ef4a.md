# 결정론적 오류는 자동 재시도에서 뺀다

## Definition

재시도해도 같은 결과가 나오는 오류(설정 오류, 요청 조립 버그, 잘못된 URL)는 자동 재시도 대상에서 빼고 알림으로 사람에게 넘기며, DB 장애·슬롯 경합·연결 실패 같은 일시적 오류만 재시도한다.

## Evidence

- 결정론적 오류를 무조건 재시도하면 최대 재시도 횟수만큼 헛돈다.
- 분류 예: 200 + 실패 코드(일시적, 재시도), 409 슬롯 경합(일시적, 재시도), 400/422 요청 검증 실패(러너 버그, 제외), 404/405(설정 오류, 제외), 서버 환경 문제로 인한 500(제외), 연결 실패·read timeout(일시적, 재시도).
- 구현은 기존 재시도 조회가 이미 쓰는 '자동 재시작 허용' 플래그를 실패 시 내리는 방식으로 하면 조회 SQL 을 고치지 않아도 된다.
- 양쪽 설정 불일치(예: 집계 구간 길이)는 검증을 건너뛰고 조용히 이중 집계되는 것보다 400 으로 즉시 실패하는 편이 낫다. 그러려면 그 값을 요청에 반드시 실어 보내야 한다.
