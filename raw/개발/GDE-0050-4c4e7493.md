# pg_dump와 psql 파이프로 스키마 복제와 테이블 데이터 이관

## Purpose

PostgreSQL 스키마 구조를 다른 이름의 스키마로 복제하거나, 중간 파일 없이 서버 간에 조건부로 테이블 데이터를 옮긴다.

## Steps

1. 구조만 덤프한다: `pg_dump -h <host> -U <user> -d <db> -n <schema> -s -c -f schema_dump.sql` (`-s` 구조만, `-c` DROP 포함).
2. 대상 스키마명으로 치환한다: `sed -i '' 's/<원스키마>/<새스키마>/g' schema_dump.sql` (macOS sed는 `-i ''`).
3. 대상 서버에 적용한다: `psql -h <host> -U <user> -d <db> -f schema_dump.sql`.
4. 조건부 데이터 이관은 COPY를 파이프로 잇는다: `psql <원본> -c "COPY (SELECT * FROM <schema>.<table> WHERE <date_col> >= '<start>') TO STDOUT" | psql <대상> -1 -c "COPY <schema2>.<table> FROM STDIN"`. `-1`로 테이블마다 단일 트랜잭션이 된다.
5. 여러 테이블은 배열로 두고 반복문으로 4번을 실행한다.
6. INSERT 문 형태가 필요하면 `pg_dump --data-only --column-inserts -t <table> | sed 's/<원스키마>\./<새스키마>./g' | psql <대상>`을 쓴다.
