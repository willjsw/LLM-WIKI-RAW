# Heap 사용 추이로 메모리 누수를 판별하는 기준

## Definition

Heap 메모리 누수는 최고점이 아니라 Full GC 직후의 최저점 추이로 판별한다. GC 후 최저점이 계속 우상향하면 GC로 회수되지 않는 객체가 쌓이고 있다는 뜻이며, 조치하지 않으면 결국 OOM이 난다.

## Evidence

| 패턴 | 판정 |
|---|---|
| Minor GC: 등락폭 작고 주기 잦음 | 정상 |
| Full GC: Minor GC 사이에서 급락 | 정상 |
| GC 후 저점이 끊김 없이 우상향 | 누수 |

- Java 프로세스 메모리는 Java Heap + Metaspace(Perm) + JVM 자체 메모리의 합이며, Heap Dump는 Java Heap만 담는다
- 하루 수 MB씩 느리게 늘어나는 누수는 정기 재기동에 가려지므로, 일·주 단위로 Heap Dump를 떠서 같은 클래스의 두 시점 스냅샷을 비교(compare)해 증가분을 추적한다
