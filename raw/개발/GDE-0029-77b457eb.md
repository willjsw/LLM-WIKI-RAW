# 일반 테이블을 파티션 테이블로 전환하고 데이터 이관하기

## Purpose

운영 중인 일반 테이블을 RANGE 파티션 테이블로 바꾸고 기존 데이터를 옮긴다.

## Steps

1. 새 DDL 을 준비한다: 파티션 키를 NOT NULL(필요하면 DEFAULT 포함)로 승격하고, 테이블 끝에 `PARTITION BY RANGE (<키>)`, PK 말미에 파티션 키를 추가한다. 제약은 `ALTER TABLE`(ONLY 없이)로 건다.
2. 파티션 정책 테이블에 대상 테이블(키, 단위, 보관 수, 선행 생성 수)을 등록한다.
3. 트랜잭션을 연다: `BEGIN;`.
4. 기존 테이블을 `ALTER TABLE t RENAME TO t_old;` 로 비켜 둔다.
5. 새 DDL 로 `t` 를 다시 만든다.
6. 이관할 기간의 파티션을 먼저 만든다(유지보수 프로시저 호출). 없으면 INSERT 가 `no partition of relation` 으로 실패한다. 이관 데이터가 보관 기간보다 오래되었으면 정책 값을 임시로 올리거나 파티션을 수동 생성한다.
7. `INSERT INTO t SELECT ..., COALESCE(<키>, <대체 시각컬럼>) FROM t_old;` 로 옮기며 NULL 을 보정한다.
8. `COMMIT;` 후 건수·조회를 검증하고 나서 `DROP TABLE t_old;` 한다.
