# 프로세스 가상 주소 공간의 메모리 영역

## Definition

프로세스는 실행 중인 프로그램이며, 디스크의 실행 파일(리눅스 ELF, 윈도우 PE)이 로드되면 가상 주소 공간에 Text, Data, BSS, Heap, 메모리 매핑 영역, Stack이 배치된다. Text·Data·BSS는 정적 할당, Heap·Stack은 동적 할당 영역이다.

## Evidence

| 영역 | 내용 |
|---|---|
| Text | 코드, 상수(rodata) |
| Data | 초기화된 전역·정적 변수 |
| BSS | 초기화되지 않은 전역·정적 변수(0으로 채움) |
| Heap | malloc 등 동적 할당, 위로 성장 |
| Memory Mapping | 파일 매핑, 동적 라이브러리 |
| Stack | 지역변수, 함수 인자·리턴 값, 아래로 성장(RLIMIT_STACK) |
| Kernel space | 유저 코드 접근 시 Segmentation Fault |

- ASLR이 스택·mmap·brk 시작 위치를 무작위화한다
- `readelf -a`, `nm`, `file`로 실행파일 형식과 심볼 주소를 확인할 수 있다
