# SECURITY DEFINER 함수의 실행 권한 주체

## Definition

PostgreSQL 에서 SECURITY DEFINER 로 선언한 함수·프로시저는 호출한 계정이 아니라 그 객체의 소유자(OWNER) 권한으로 실행된다. 그래서 객체 소유자를 바꾸면 실행 시점의 권한 주체가 바뀐다.

## Evidence

- 소유자만 가능한 작업(예: 부모 테이블에 파티션 생성·분리)을 다른 계정이 호출하게 하려면, 그 작업을 하는 SECURITY DEFINER 함수의 OWNER 를 대상 테이블 소유자로 지정한다.
- 호출 계정에는 진입점 프로시저의 EXECUTE 와 스키마 USAGE 만 주면 된다.
- 함수·프로시저는 만들 때 PUBLIC 에 EXECUTE 가 기본 부여되므로, SECURITY DEFINER 객체는 `REVOKE EXECUTE ... FROM PUBLIC` 후 필요한 계정에만 GRANT 해야 한다. 그러지 않으면 아무 계정이나 소유자 권한으로 실행할 수 있다.
- 소유 현황은 `pg_proc` 의 `proowner`, `prosecdef` 로 확인한다.
