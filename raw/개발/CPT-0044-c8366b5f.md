# 브라우저 자동화 에이전트의 동작 구조

## Definition

브라우저 자동화 에이전트는 SDK가 LLM에 목표를 주고, LLM이 Playwright로 브라우저를 조작한 뒤 스크린샷을 다시 LLM에 돌려주는 ReAct 루프로 사람처럼 웹 UI를 다룬다. 전통적 UI 자동화의 도입 기간, 취약성, 사이트 종속성 한계를 줄이려는 접근이다.

## Evidence

- 전통적 자동화의 한계: 워크플로 하나에 수 주~수 개월, UI 변경에 쉽게 깨짐, 다른 사이트에 재사용 불가
- 행동 경로는 Trajectory 로그로 기록해 추적한다
- 활용 예: 이슈 트래커의 테스트 케이스를 읽어 브라우저 QA 수행, 엑셀 입력값으로 웹폼·PDF 자동 입력
- 신뢰성은 Human-in-the-Loop 개입으로 보완한다
