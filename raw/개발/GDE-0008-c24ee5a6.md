# Redis Stream 파티션 소유자 교체 시 PEL 인수 절차

## Purpose

파티션 소유 인스턴스가 죽었을 때 새 소유자가 미확인 메시지를 잃지 않고, 파티션 순서를 지키며 이어서 처리하게 한다.

## Steps

1. 옛 소유자의 리스가 만료되면 새 인스턴스가 다음 세대 리스를 획득하고 토큰에 자기 식별자를 기록한다.
2. 획득 직후 `XPENDING` 으로 consumer group 의 PEL 을 확인한다.
3. `XAUTOCLAIM` 으로 이른 Stream ID 부터 인수한다. 최소 유휴 시간이 지나지 않은 항목은 가져오지 못하므로, 당장 가져온 항목이 없어도 `XPENDING` 에 선행 항목이 있으면 가져올 수 있을 때까지 기다린다.
4. 선행 PEL 항목을 처리하기 전에는 새로 읽은 뒤 레코드의 적재를 보류한다. 이 대기가 발행 측 `XADD` 를 막지는 않는다.
5. 새 레코드를 읽는 동안에도 선행 PEL 이 남았는지 주기적으로 확인한다.
6. 목적지 전달이 확인된 메시지만 `XACK` 한다. 응답이 없으면 같은 항목을 재시도하고, 수신 측은 `eventId` 로 중복을 막는다.
7. 검증 시나리오로 읽은 직후 중단, 적재·XACK 전후 중단, 오래된 토큰 거부, 선행 순서를 시험한다.
