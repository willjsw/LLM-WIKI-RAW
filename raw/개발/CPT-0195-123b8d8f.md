# 커밋된 API 스펙과 코드 생성 스펙 일치를 CI로 강제

## Definition

코드에서 자동 생성되는 OpenAPI 스펙을 저장소에 파일로 커밋해 두고, CI 테스트가 '커밋된 스펙'과 '지금 코드가 생성하는 스펙'이 같은지 비교해 다르면 빌드를 실패시키는 방식이다. 스펙과 코드가 어긋난 채 머지되는 것을 막아 스펙 파일을 diff 가능한 계약으로 쓸 수 있게 된다.

## Evidence

- 스펙은 단일 JSON 파일로 두고 키를 정렬해 diff 노이즈를 줄인다.
- operationId를 모든 operation에 명시하고 유일하게 부여하면 메서드 이름을 바꿔도 변경으로 잡히지 않는다.
- 인증 정보에서 파생되는 파라미터가 스펙에 노출되면 문서 생성기에서 숨겨 노이즈를 없앤다.
- 소비 측(FE)은 매핑 prefix가 스펙에 실제 있는지 검증하는 스크립트로 매핑 파일의 정합성을 지킨다.
