# 근거 기록 기반 콜 레그 연결과 세션 병합

## Definition

호전환·협의통화로 갈라진 콜 레그들을 하나의 세션으로 묶을 때, 연결 근거를 confidence와 score와 함께 모두 기록하고 임계값을 넘는 근거만 병합에 쓰는 방식이다. 판정 근거가 남으므로 나중에 규칙을 바꿔 재판정할 수 있다.

## Evidence

- 근거 후보 우선순위 예: 1) 직전 콜 ID(preUcid, 일정 시간 이내) 2) UUI 안의 원콜 정보, 원 Call ID 3) 교환기 ID, 시각, 테넌트로 가장 유사한 콜. 같은 상담사가 보류 후 짧은 시간(예: 3초) 안에 새 콜을 만들면 협의통화 근거로 본다.
- 교환기 종류마다 콜 ID 규칙이 다를 수 있으므로 교환기 유형별로 추적 규칙을 모듈화하는 방안이 검토됐다.
- 병합은 union-find 형태로 대표 세션을 정하고, 대표는 가장 먼저 생긴 콜 ID로 한다. alias 매핑은 CAS로 갱신하고 충돌 시 제한 횟수(예: 5회) 재시도한다.
- 레거시처럼 preUcid가 오는 즉시 메모리 Map에서 세션 UUID를 공유하는 방식은 영속되지 않아 재기동 시 연결이 끊긴다.
- 리스크: 샤드 라우팅은 원콜 ID를 세션 키로 보는데 병합 winner는 "가장 이른 콜 ID"라면, 둘이 다를 때 귀속이 갈라질 수 있다(추정, 검증 필요).
