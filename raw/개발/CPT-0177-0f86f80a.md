# DB 정의 기반 Quartz 동적 Job Chain

## Definition

Job과 Job 간 선후 관계(Chain)를 DB 테이블에 정의하고, Quartz JobListener가 Job 종료 시 결과(성공/실패)에 맞는 자식 Job을 찾아 즉시 트리거하는 구조다. 체인의 첫 Job만 cron을 갖고 나머지는 앞 Job의 완료로 실행된다.

## Evidence

- 구성: Quartz Job 어댑터(QuartzJobBean)와 실제 실행 로직(JobRunner 구현체)을 분리하고, Job 유형(Python 스크립트, Java 배치, 프로시저 등)마다 Runner를 둔다.
- 기동 시 로더가 DB의 enabled Job을 Quartz에 등록하고 체인 리스너를 등록한다.
- 체인 행에는 parent, child, onSuccess, onFailure, enabled, priority를 둔다. 예: 일별 집계 프로시저 8개를 onSuccess=true, onFailure=false로 직렬 연결하고 첫 Job만 자정 cron을 건다.
- 자식이 없으면 리스너가 'No next jobs'를 로그로 남긴다.
- 실행 이력은 READY → IN_PROGRESS → COMPLETED/FAILED 상태로 별도 테이블에 쌓는다.
- 프로시저 명령의 `${YESTERDAY}` 같은 치환자는 실행 시점에 해석한다.
