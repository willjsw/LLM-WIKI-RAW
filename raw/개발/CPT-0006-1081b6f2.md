# 헤드리스 Claude Code 를 API 백엔드 실행 주체로 쓰기

## Definition

API 서버가 요청을 받으면 미리 정의한 프롬프트로 Claude Code 를 헤드리스 모드로 실행해, AI 에이전트가 데이터 조회·검증·결과 작성을 수행하고 그 결과를 HTTP 응답으로 돌려주는 구조다. AI 가 코딩 보조가 아니라 시스템의 런타임 실행 주체가 된다.

## Evidence

통계 모듈 테스트 자동 채점 서버에서 테스트한 콜 식별자를 받아 DB 의 관련 테이블을 조회하고, 헤드리스 Claude 가 이벤트를 시간순 정렬·검증해 응답하며, 결과를 스프레드시트 MCP 로 기록했다. 첫 단계 목표는 검증 정확도가 아니라 조회부터 헤드리스 호출, 응답까지 루프 하나가 도는지 확인하는 것이었다. AI 실행 비용을 관측하려고 토큰 사용량을 테스트 결과에 함께 남겼다. DB 는 읽기 전용 계정으로 접근한다.
