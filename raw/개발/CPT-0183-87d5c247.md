# SIP SUBSCRIBE와 NOTIFY, BLF

## Definition

SUBSCRIBE/NOTIFY는 SIP에서 다른 개체의 상태 정보를 구독하고 변화가 생길 때 통지받는 메커니즘이다. 단말의 내선 상태 표시등(BLF, Busy Lamp Field)이 이 위에서 동작한다.

## Evidence

- 최초 SUBSCRIBE를 보내면 초기 NOTIFY로 현재 상태를 받는다.
- 이후 구독 대상의 상태가 바뀔 때마다 NOTIFY가 온다. 본문은 Event 패키지 규격에 따라 XML 등으로 전송된다.
- Event 패키지는 서비스마다 다르며 표준인 경우도, 아닌 경우도 있다.
