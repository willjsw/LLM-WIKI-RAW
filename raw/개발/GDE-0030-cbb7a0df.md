# 결정론 암호화 컬럼 운영 규칙

## Purpose

결정론 암호화 컬럼에서 예외 없이 조회만 실패하는 사고를 막는다.

## Steps

1. 입력 정규화(대소문자, 공백, 구분기호, Unicode NFC)를 호출자 한 곳에 모은다. 예: `<SEC-phone 예시>` 과 `<SEC-phone 예시>` 은 다른 암호문이 된다.
2. 같은 데이터를 다른 언어 서비스도 암호화한다면 정규화 규칙을 모든 소비처에서 똑같이 맞춘다.
3. AAD 는 컬럼 단위로 고정한다. 행마다 다른 AAD 를 쓰면 같은 값의 암호문이 달라져 검색이 깨진다.
4. 값 종류가 적은 컬럼(성별, 등급)에는 결정론 모드를 쓰지 않는다.
5. 검색 컬럼에 랜덤 모드 암호문이 섞이면 조용히 0건이 되므로, 쓰기 시점 검증과 정기 점검에서 헤더로 결정론 여부를 판별한다.
