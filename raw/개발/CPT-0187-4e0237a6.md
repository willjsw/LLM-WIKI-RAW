# 착신전환 3유형과 당겨받기

## Definition

착신전환은 걸려 온 호를 다른 번호로 돌리는 기능으로 무조건(Unconditional), 통화중(Busy), 무응답(No Answer) 세 유형이 있다. 당겨받기(Call Pickup)는 다른 단말에 울리는 호를 내 단말에서 받는 기능이다.

## Evidence

- 무조건: 설정 즉시 모든 착신이 전환 단말로 간다.
- 통화중: 원래 단말이 통화 중일 때만 전환하고, 통화 중이 아니면 원래 단말이 울린다.
- 무응답: 원래 단말이 일정 시간(시험에서는 20초) 응답하지 않으면 전환 단말이 울린다.
- 설정은 단말에서 기능 코드(FAC) + 대상 번호로 하고, 성공 시 안내 멘트가 나온다.
- 당겨받기: Direct(특정 내선 지정) 또는 Group(같은 당겨받기 그룹 소속). 단말 물리 버튼에 매핑된 기본 코드는 단말 웹 설정에서 바꾼다.
- 발신/착신 제한은 제한 방향(발신, 착신)과 회선 종류(내부, 공중망, 국제)의 조합으로 설정한다.
