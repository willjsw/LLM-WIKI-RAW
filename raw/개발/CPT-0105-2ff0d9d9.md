# MCP 의 Tools Resources Prompts 는 누가 고르느냐로 나뉜다

## Definition

MCP 서버의 세 기능은 사용 주체로 구분된다. Tool 은 모델이 대화 중 스스로 호출하는 동작, Resource 는 앱·사용자가 컨텍스트로 붙이는 읽기 전용 데이터(URI), Prompt 는 사용자가 명시적으로 고르는 작업 템플릿(모델에게 보낼 메시지 생성)이다.

## Evidence

- Tool: `tools/call`(이름 + JSON 스키마 인자), 부작용이 있을 수 있다. Claude Code 에서는 모델이 `mcp__<서버>__<tool>` 로 호출한다.
- Resource: `resources/read`(URI), 부작용 없음. 인자가 필요하면 리소스 템플릿(`scheme://path/{param}`)을 쓴다. Claude Code 에서는 사용자가 `@` 로 첨부한다.
- Prompt: `prompts/get`(이름 + 인자), 인자는 모두 문자열이라 직접 검증해야 한다. Claude Code 에서는 `/mcp__<서버>__<prompt>` 슬래시 명령이 된다.
- 여러 기능의 조합은 서버에 따로 두지 않고 에이전트(클라이언트)가 맡는다. 서버 측 복합 tool 이 필요한 경우는 따로 있다: 매번 같은 범위로 비교 가능한 결과가 필요할 때(모델은 범위를 매번 다르게 고른다), 데이터가 커서 서버에서 집계해야 할 때, 사람 없는 정기 실행, 단계 실패 시 되돌림이 필요할 때.
- 사내 데이터를 외부 서비스로 옮기는 조합은 반출 승인 대상인지 먼저 확인한다.
