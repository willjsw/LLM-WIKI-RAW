# 에이전트 운영 레이어(AgentCore형 플랫폼)의 구성

## Definition

에이전트 운영 레이어는 이미 만든 에이전트(Strands, LangGraph 등)를 프레임워크 교체 없이 올려, LLM만으로 해결되지 않는 격리·인증·메모리·평가·관측 문제를 맡는 플랫폼 계층이다. Amazon Bedrock AgentCore가 대표 사례다.

## Evidence

- Runtime: 서버리스 실행, 마이크로 VM 기반 세션 격리
- Identity/Policy: 비인간 주체의 인증·인가·자격증명 관리와 행동 범위 통제
- Memory: 단기→장기 메모리 관리
- Gateway: 기존 API·Lambda를 에이전트 호환 도구로 변환해 MCP로 노출
- Observability: 에이전트 행동 추적
- Evaluations: 1회성이 아닌 지속적·On-Demand 평가로 승격/롤백을 결정
- 자체 운영 시 겪는 문제: 멀티 데이터 소스 관리 복잡, 가시성 부족, 병목 식별 곤란, 인프라(ECS/ALB/DB) 운영 부담 → 운영 레이어로 옮겨 단일 진입점과 운영 단순화를 얻은 사례가 있다
