# 로그성 테이블은 월 단위 파티션으로 나눠 DROP 으로 지운다

## Definition

주기적으로 지워야 하는 로그·통계 적재 테이블을 월 단위 파티션으로 저장하면, 보관 기간이 지난 데이터를 행 단위 DELETE 대신 파티션 DROP 한 번으로 지울 수 있어 I/O 부하가 거의 없다.

## Evidence

- 매월 수십만 건을 DELETE 로 지우면 I/O 부하가 커져 시스템 장애 요인이 된다. DELETE 수만 건이 DROP 한 줄로 바뀐다.
- 파티션 생성·삭제는 프로시저로 자동화한다. 대상 테이블이 수십 개면 수동 작업은 누락되기 쉽고, 다음 달 파티션 생성이 누락되면 적재 자체가 실패해 즉시 장애가 난다.
- 자동화 프로시저의 실행 권한(소유자)이 부모 테이블과 맞아야 한다.
