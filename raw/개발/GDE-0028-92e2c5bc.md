# npm 사설 registry 인증 설정

## Purpose

로그인이 필요한 사설 npm registry 에서 설치하고 배포한다.

## Steps

1. `~/.npmrc` 에 `registry=<다운로드(group) registry 주소>` 를 쓴다.
2. 다운로드·배포 registry 각각에 `//<호스트/경로>/:_auth=<인증값>` 줄을 추가하고 `always-auth=true` 를 둔다.
3. 인증값은 `echo -n '계정:비밀번호' | base64` 로 만든다.
4. 배포할 패키지는 package.json 의 `publishConfig.registry` 를 배포(hosted) registry 주소로 지정한다.
5. .npmrc 에는 비밀번호에 해당하는 값이 들어가므로 Git 에 커밋하거나 공유하지 않는다.
