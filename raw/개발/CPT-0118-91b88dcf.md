# STOMP 1.2 프레임 구조와 명령

## Definition

STOMP 는 WebSocket 같은 통로 위에서 목적지·구독·확인·오류 통지를 정한 텍스트 기반 메시징 규약이다. 프레임은 명령 1줄, 헤더 여러 줄, 빈 줄, 본문, NULL 바이트 순서로 구성된다.

## Evidence

- 보통 WebSocket 메시지 1개에 STOMP 프레임 1개를 담는다. 표기 `^@` 는 실제로 0x00 바이트 하나다.
- 클라이언트 명령: CONNECT(또는 STOMP), SEND, SUBSCRIBE/UNSUBSCRIBE, ACK/NACK(구독 ack 가 client 계열일 때), BEGIN/COMMIT/ABORT, DISCONNECT.
- 서버 명령: CONNECTED, MESSAGE, RECEIPT(receipt 헤더 요청 처리 확인), ERROR(보낸 뒤 서버가 연결을 닫는다).
- 주요 헤더: `destination`(형식은 서버가 정함), SUBSCRIBE 의 `id` 와 MESSAGE 의 `subscription` 짝, `message-id`(서버 프레임 식별자로 앱 메시지 ID 와 별개), `ack`(auto 기본 / client / client-individual), `host`(1.2 필수).
- 헤더 값의 `\r` `\n` `:` `\` 는 이스케이프한다(CONNECT·CONNECTED 예외). 같은 헤더가 반복되면 첫 값이 유효하다.
- 기본 흐름: CONNECT → CONNECTED → SUBSCRIBE → SEND → MESSAGE → DISCONNECT(receipt) → RECEIPT. 구독 전에 발행된 메시지는 받지 못하므로 구독을 먼저 한다.
