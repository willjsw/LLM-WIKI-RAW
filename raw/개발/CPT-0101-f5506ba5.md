# 여러 단계를 거친 세션 통계를 최초 단계에 귀속시키는 집계

## Definition

한 세션(콜)이 여러 큐를 거치며 단계별 행을 남길 때, 세션별 최초 행(DISTINCT ON 으로 가장 이른 1행)에서 귀속 기준(일시, 큐 ID, 인입 건수)을 가져오고, 수치는 세션별로 따로 합계·최대를 낸 뒤 둘을 세션 키로 조인하는 집계 방식이다.

## Evidence

- 단계별 행을 그대로 큐 기준으로 합하면 큐를 옮겨 다닌 콜이 인입 건수에 여러 번 잡힌다. 최초 행에서만 인입 건수를 가져오면 콜당 1건이 된다.
- 처리량·시간 합계(통화 건수, 대기·통화·후처리 시간, 포기 건수 등)는 세션의 모든 단계를 SUM 한다.
- 최대 대기 시간 같은 값은 `max(COALESCE(값, 0))` 처럼 NULL 을 0 으로 바꾼 뒤 MAX 한다.
- 같은 시각에 두 행이 있을 수 있으면 정렬 기준에 최초 이벤트 시각 같은 동률 해소 컬럼을 추가해 결과를 결정적으로 만든다.
- 여러 카운터를 합친 지표(예: 무응답 회수 + 재큐잉)는 각각 COALESCE 후 더한다. 하나라도 NULL 이면 합이 NULL 이 되기 때문이다.
