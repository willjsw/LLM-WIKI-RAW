# 리스와 펜싱 토큰으로 파티션 소비 소유권 관리

## Definition

파티션 스트림마다 TTL 이 있는 리스를 두고 그 소유자 한 명만 소비하게 하며, 리스에 세대(epoch) 번호를 넣은 펜싱 토큰으로 발급해 만료된 옛 소유자의 뒤늦은 쓰기를 거부한다.

## Evidence

- 소유자가 없으면 분산 락(예: Redisson)으로 획득하고, TTL 만료로 데드락을 막는다. 소유자는 주기적으로 갱신하고, 각 인스턴스는 미소유 파티션 획득을 주기적으로 시도한다.
- 멈췄다 깨어난 좀비 소유자가 옛 토큰으로 큐 적재·`XACK` 를 시도하면, 같은 Redis primary 에서 '토큰 확인 → eventId 중복 확인 → 적재 → 중복 기록 → XACK' 를 한 Lua/Function 호출로 묶어 현재 토큰과 다르면 둘 다 거부한다. Sentinel 은 Cluster hash slot 제약이 없어 관련 키를 한 primary 에 둘 수 있다.
- 읽기 전 확인만으로는 부족하다. 확인 직후 리스가 만료될 수 있고 `XREADGROUP` 으로 받은 항목은 PEL 에 남는다. `XREADGROUP BLOCK` 은 시간을 제한하고 소유권을 잃으면 대기 중인 읽기를 중단한다.
- 세대 검증은 구독 요청에도 쓴다. 재기동된 옛 인스턴스가 만료된 세대로 구독하면 거절한다.
- 운영 전에 리스 TTL·갱신 주기·획득 시도 주기를 정해야 한다.
