# 신규 환경 DB 객체 생성 순서

## Purpose

새 환경에 애플리케이션 DB를 구축할 때 의존 관계 오류 없이 객체를 만들고 검증한다.

## Steps

1. 애플리케이션 사용자(계정)를 만든다. OS·DB 계정명에 admin, sys 같은 예약성 이름은 쓰지 않는다.
2. 스키마 생성과 객체 생성 권한을 부여한다.
3. 스키마를 만든다.
4. 시퀀스를 먼저 만든다(테이블 기본값이 참조).
5. 테이블을 만든다(컬럼, 타입, 기본 제약조건).
6. PK를 만든다(별도 관리 시).
7. FK를 만든다.
8. 인덱스를 만든다.
9. 뷰를 만든다.
10. 함수를 만든다.
11. 프로시저를 만든다.
12. 트리거를 만든다.
13. 공통 코드, 환경 설정 같은 초기 데이터를 넣는다.
14. 사용자별 객체 권한(SELECT, INSERT 등)을 부여한다. 테이블뿐 아니라 시퀀스 권한도 함께 준다.
15. 애플리케이션 연결과 CRUD를 테스트한다.
16. 인덱스와 실행 계획을 점검한다.
17. 초기 백업과 유지보수 정책을 설정한다.
