# ULID와 UUIDv7 차이

## Definition

ULID와 UUIDv7은 둘 다 앞부분에 밀리초 타임스탬프를 넣어 생성 순서대로 정렬되는 식별자다. ULID는 UUIDv7 표준 이전에 커뮤니티에서 제안된 비표준 형식이고, UUIDv7은 RFC 9562(2024)로 표준화된 UUID 버전이다. 둘은 같은 형식이 아니다.

## Evidence

| 구분 | ULID | UUIDv7 |
| --- | --- | --- |
| 표준 | 비표준(커뮤니티 제안) | RFC 9562 표준 |
| 표현 | 26자 Crockford Base32 | 36자 16진수 8-4-4-4-12 |
| 시간 정밀도 | 밀리초 | 밀리초 기본, 서브 밀리초 옵션 |

- DB의 UUID 타입이나 표준 라이브러리 호환이 필요하면 UUIDv7이 유리하다.
