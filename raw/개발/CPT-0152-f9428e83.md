# 사람용 출력을 기계가 다시 파싱하지 않는다

## Definition

프로그램 간 연동은 결과를 구조화된 데이터(목록·JSON)로 주고받고, 사람이 읽는 텍스트 출력은 그 데이터를 그리는 표현 계층으로만 둔다는 원칙이다. 사람용 문구를 정규식으로 다시 읽으면 문구나 정렬만 바꿔도 소비자가 조용히 깨진다.

## Evidence

- 사례: 상태 명령이 진단 명령의 사람용 출력을 `"  (ok  |warn|FAIL) … — …"` 패턴으로 파싱하고 특정 기호가 없는 줄을 절 제목으로 봤다. UI 홈과 진단 화면이 문구 하나에 깨질 수 있어 두 AI 감사가 모두 지적했고 심각도를 상으로 올렸다.
- 수정안: 진단 함수가 결과를 목록으로 모아 반환하고(출력 함수가 목록에도 쌓음), 텍스트 출력과 JSON 출력은 그 목록을 그리는 쪽으로 나눈다.
- 같은 패턴: 리뷰 루프가 리뷰어(LLM) 출력의 판정 줄·제목 마크다운 형식을 파싱한다. 장기적으로 리뷰어가 JSON 결과 파일을 함께 내게 해 형식 결합을 끊는다.
- 같은 패턴: 진단이 본문에 `TBD`·`미검증` 같은 일반 문자열이 있는지로 판정 → `<!-- TBD` 같은 고정 표지로 좁힌다.
- UI 가 CLI 를 우회해 파일을 직접 쓰거나 CLI 로직을 표지 문자열까지 복제한 경우도 같은 결합이다. 쓰기는 CLI 명령(stdin 입력)으로, 경로·스키마는 CLI 의 schema 출력으로 일원화한다.
