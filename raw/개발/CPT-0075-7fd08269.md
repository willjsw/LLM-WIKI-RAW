# 응답시간은 CPU 시간과 대기 시간의 합이다

## Definition

응답시간은 서비스 로직의 CPU 연산 시간과 자원을 얻기 위해 기다린 대기 시간의 합이다. 응답이 느리면 먼저 둘 중 어느 쪽인지 구분해야 하며, 실무 문제 대부분은 대기 시간이고 그 정체는 자원 경합(동기화)이다.

## Evidence

| 대기 자원 | 지연 예 | 개선 |
|---|---|---|
| CPU | 요청 증가로 CPU 할당 지연 | 비효율 코드 개선, 증설 |
| Memory | 대용량 조회로 스와핑, JVM GC 시간 증가 | 대용량 요청 코드 개선(주기적 flush), 증설 |
| DBMS | 동일 row DML로 DB Lock, 긴 트랜잭션 | 락 구간·트랜잭션 구간 최소화 |

- 대기 자원은 CPU, Memory, Disk, Network, DBMS로 나눠 본다
- "Java 엔터프라이즈 애플리케이션은 거대한 동기화 머신이다"
