# Git 커밋 작성자 이름·이메일 일괄 변경

## Purpose

잘못된 계정(개인 이메일 등)으로 쌓인 커밋의 작성자·커미터 정보를 히스토리 전체에서 바꾼다.

## Steps

1. 히스토리 재작성은 커밋 해시를 모두 바꾸므로 공유 브랜치라면 팀과 먼저 합의하고 백업 클론을 만든다.
2. 권장 방식(filter-repo): `git filter-repo --name-callback "return name if name != b'<old_name>' else b'<new_name>'" --email-callback "return email if email != b'<old_email>' else b'<new_email>'" --force`.
3. filter-repo 가 없으면 filter-branch: `git filter-branch --env-filter '<OLD_EMAIL 과 같으면 GIT_COMMITTER_NAME/EMAIL, GIT_AUTHOR_NAME/EMAIL 을 새 값으로 export>' --tag-name-filter cat -- --branches --tags`. author 와 committer 를 둘 다 바꿔야 한다.
4. `git log --format='%an <%ae> / %cn <%ce>'` 로 결과를 확인한다.
5. 원격에 반영하려면 force push 가 필요하다.
6. 앞으로는 저장소별 `git config user.name/user.email` 을 맞춰 재발을 막는다.
