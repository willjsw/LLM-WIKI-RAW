# AI-Ready Data와 시맨틱 레이어의 4가지 장벽

## Definition

AI-Ready Data는 메타데이터·품질·거버넌스가 정비되어 AI가 실제로 사용하고 분석할 수 있는 데이터다. LLM과 데이터 사이에 시맨틱 레이어를 두어 맥락·연결·추론·신뢰의 네 장벽을 단계적으로 해소한다.

## Evidence

| 장벽 | 해결 수단 |
|---|---|
| 맥락 | RAG, 벡터 검색 |
| 연결 | 지식 그래프로 관계 정보 제공 |
| 추론 | 온톨로지(업무 개념·규칙·논리 제약) |
| 신뢰 | 출처·정책·의사결정·설명을 제공하는 시맨틱 레이어 |

- 에이전트는 실제로 행동하므로 컬럼 매핑 실패·데이터 모호성이 모델 성능과 무관한 실패를 낳는다
- "더 많은 데이터 < 의미를 담은 데이터"
- 메타데이터는 운영·비즈니스·테크니컬 세 종류로 관리한다
- 기존 시스템은 그대로 두고 시맨틱 레이어만 추가하는 접근이 가능하다
- 데이터 생산자·기술·소비자 세 주체가 함께 일하는 운영 모델이 선행되어야 한다
