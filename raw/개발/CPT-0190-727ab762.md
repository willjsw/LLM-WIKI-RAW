# 발행·수신 모듈과 파티션을 담은 Redis Stream 키 규칙

## Definition

모듈 간 메시지 스트림 키를 `{ENV}:<Channel>:<발행 모듈>:<수신 모듈>:{Partition}`처럼 환경, 채널, 발행 모듈, 수신 모듈, 파티션 번호로 구성하는 규칙이다. 스트림이 경로와 파티션별로 나뉘어 한 스트림만 비대해지지 않는다.

## Evidence

- 파티션 번호는 대화 ID 해시로 정해 같은 대화가 같은 스트림으로 간다.
- 메시지는 헤더와 payload로 나눠, 수신 측이 payload를 역직렬화하기 전에 헤더(메시지 타입 등)만 보고 분기한다.
- 키에 FROM/TO 모듈을 넣으면 어떤 경로의 트래픽인지 키만 보고 알 수 있다.
