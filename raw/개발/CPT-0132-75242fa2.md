# SIP INVITE 호 수립과 SDP offer-answer

## Definition

SIP 통화는 발신 측이 SDP offer 를 담은 INVITE 를 보내고, 착신 측이 받으면 SDP answer 를 담은 200 OK 로 답한 뒤 발신 측이 ACK 를 보내 수립된다. 미디어 IP·포트·코덱은 SDP 협상으로 정해진다.

## Evidence

- 순서: A → INVITE(SDP offer) → 교환기가 B 의 등록 주소를 찾아 INVITE 전달 → 100 Trying(교환기→A) → 180 Ringing → B 응답 시 200 OK(SDP answer) → A 가 원격 answer 를 적용해 협상 완료 → A → ACK.
- SDP 는 SIP 메시지 body 에 실린다. 하나의 메시지에 body 가 여러 개(multipart) 올 수도 있다.
- 스택의 Call-ID 와 애플리케이션이 쓰는 호 식별자는 다를 수 있으니 매핑을 따로 관리한다.
