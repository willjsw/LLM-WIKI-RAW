# AI 에게 작업을 맡기는 컨텍스트 제공과 검증 방법

## Purpose

여러 레이어에 걸친 개발 작업을 AI 에게 맡길 때 결과가 기존 구조와 맞고 검증 가능하게 한다.

## Steps

1. 따라 할 기존 구조를 레퍼런스로 지정한다("기존 X 의 구조를 최대한 활용해서 Y 를 추가"). 사람이 패턴을 먼저 파악하고 "그 패턴대로 확장"을 지시한다.
2. DDL, 에러 로그, 호출 예시 같은 근거 자료를 붙여 넣는다.
3. 지시는 번호 매긴 다단계로 쓰고, 단계마다 제약을 붙인다("이 테이블은 제외하고").
4. 정상 플로우부터 먼저 확인하고 예외 처리는 뒤로 미룬다("우선 ~까지만").
5. 변경 전 허가를 받게 하고, 마이그레이션 같은 위험 작업은 커밋에서 빼게 한다.
6. AI 설계 결과는 검증 지시를 따로 내려 교차 검증한다. DB 작업은 실 DB 를 단일 진실 소스로 삼아 로컬 파일과 대조한다. DB 접속은 읽기 전용 계정을 쓰고 비밀번호를 프롬프트에 평문으로 넣지 않는다.
7. 반복되는 규칙과 함정은 CLAUDE.md 나 SKILL.md 에 남겨 다음부터 매번 지시하지 않게 한다.
