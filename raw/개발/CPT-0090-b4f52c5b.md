# 실행 결과 레코드 계약 - 종료 시 마커 붙은 JSON 한 줄

## Definition

로그 형식을 통일하지 않고, 실행이 끝날 때 정해진 마커가 붙은 JSON 한 줄(예: `RESULT {"exitCode":0,"message":...,"counts":{...}}`)만 출력하도록 부모와 자식이 약속하는 방식이다. 부모는 그 줄만 해석해 성공·실패와 처리 건수를 판정한다.

## Evidence

- 프로시저·Java·Python·HTTP API 처럼 출력 통로가 다른 채널에도 각각 한 줄로 도입할 수 있다(프로시저는 `RAISE NOTICE`, Spring Batch 는 `afterJob` 리스너, Python 은 종료 직전 `print(..., flush=True)`, API 는 응답 본문).
- 필수 필드는 exitCode 하나, 여러 줄이면 마지막 것을 채택한다.
- 레코드가 없으면 기존 판정(exit code, SQLException, HTTP status)으로 되돌아가 기존 자식과 호환된다.
- 모든 로그 줄을 JSON 으로 바꾸는 방식은 stdout 이 없는 채널에 적용할 수 없고, 언어를 가로지르는 공통 로깅 라이브러리는 일반적이지 않다.
- 유사 사례: Nagios 플러그인(종료 코드 + 상태 한 줄), Ansible 모듈(stdout JSON 결과), GitHub Actions workflow command(마커 줄만 부모가 해석).
