# 용도별 마스터키 분리와 환경 변수 우선 원칙

## Definition

설정 비밀용 키와 앱 데이터용 키는 반드시 다른 값이어야 하고, 키는 커밋된 설정 파일보다 환경 변수에서 우선 읽는다.

## Evidence

- 같은 키를 쓰면 HKDF info 가 같아 도메인 분리가 없고, 설정 비밀 암호문과 앱 데이터 암호문이 서로 교환 가능해진다. 두 용도는 노출 범위와 교체 주기도 다르다.
- env 가 항상 이겨야 커밋된 설정값이 운영 env 를 덮어쓰지 않는다. 빈 값이나 빈 값으로 풀리는 플레이스홀더는 미설정으로 취급한다.
- 주입 경로: 로컬은 셸 export·IDE 실행 설정, 컨테이너는 `-e`/compose environment/k8s Secret, Jenkins 는 Credentials(Secret text) + withCredentials.
- 키를 잃으면 복구 수단이 없어 암호문을 다시 만들어야 하므로 백업 절차를 먼저 정한다.
- 키 버전 개념이 없으면 rotation 때 구 키로 복호화하고 신 키로 재암호화하는 전량 작업이 필요하다.
