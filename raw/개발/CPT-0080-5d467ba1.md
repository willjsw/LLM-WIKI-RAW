# GC 기본 알고리즘의 계보와 트레이드오프

## Definition

GC 알고리즘은 Reference Counting에서 시작해 Mark & Sweep(추적), Mark & Compact(단편화 해결), Copying, Generational, Incremental(Train), Adaptive로 발전했으며, 각 알고리즘은 정지 시간·단편화·공간 효율·오버헤드 사이의 트레이드오프를 가진다.

## Evidence

| 알고리즘 | 장점 | 단점 |
|---|---|---|
| Reference Counting | 즉시 인지, 멈출 필요 없음 | 카운트 관리 비용, 순환 참조 누수 |
| Mark & Sweep | 참조 관계를 정확히 추적 | Stop-The-World, 단편화 |
| Mark & Compact | 단편화 방지(Sliding 방식이 가장 효율적) | 참조 갱신 오버헤드, STW |
| Copying | 복사가 곧 압축, 단편화 없음 | 공간 절반 낭비, 복사 비용 |
| Generational | 젊은 세대만 자주 수집, 세대별 알고리즘 조합 | 세대 간 참조 추적 필요 |
| Train(Incremental) | 정지를 블록 단위로 분산 | 총 정지 시간 증가 가능, 단편화 |

- 이후 대부분 GC의 탐지(Detection)는 Mark & Sweep의 추적 방식을 쓴다
- Adaptive는 특정 알고리즘이 아니라 Heap 상황을 보고 알고리즘을 고르는 접근이다(HotSpot Ergonomics)
