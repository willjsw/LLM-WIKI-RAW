# 소켓 종료 시 linger 와 RST

## Definition

소켓을 닫을 때 linger 옵션을 쓰면 송신 버퍼의 데이터가 상대에게 다 전달될 때까지 종료를 미루는 우아한 종료가 되고, RST(reset)로 끊으면 버퍼에 데이터가 남아 있어도 즉시 연결을 끊는다.

## Evidence

- 프로세스가 정리 없이 죽어도 OS 는 한동안 그 TCP 연결과 버퍼를 붙잡고 있다.
- RST 는 쌓여 있는 다른 패킷보다 우선 처리되어 상대 쪽에서 미전송 데이터가 버려질 수 있다.
- 블로킹 중 들어온 데이터는 커널의 수신 버퍼에 머문다.
- 수신 측은 메시지 길이를 미리 알 수 있게 길이 필드(TLV 등)를 두는 프로토콜이 처리하기 쉽다.
