# REST API로 스케줄러 Job과 Chain을 멱등 등록하는 쉘 스크립트

## Purpose

DB에 직접 접속하지 않고 스케줄러 REST API만으로 Job과 Chain 정의를 환경마다 반복 등록한다.

## Steps

1. 스크립트 첫 줄에 `set -euo pipefail`을 둔다.
2. 대상 호스트·포트를 환경변수로 받고, 비어 있으면 사용법을 출력하고 종료한다. `command -v curl`로 의존성을 확인한다.
3. `--dry-run` 인자를 받아 실제 전송 없이 요청 내용만 출력하는 모드를 둔다.
4. Job·Chain 정의를 heredoc 안에 JSON 한 줄씩 넣는다. 빈 줄과 `#`으로 시작하는 줄은 건너뛰어 임시 비활성화를 주석으로 처리한다.
5. 서버 API는 upsert(Job)와 createOrReplace(Chain)로 만들어 여러 번 실행해도 결과가 같게 한다.
6. Job을 먼저 등록하고 Chain은 나중에 등록한다(Chain이 Job 이름을 참조).
7. `curl -s -o <tmp> -w "%{http_code}"`로 상태 코드를 받아 2xx가 아니면 응답 본문 앞 몇 줄을 출력한다.
8. 마지막에 Job·Chain 처리 건수를 출력한다.
