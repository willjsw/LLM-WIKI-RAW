# CQ 기반 온톨로지 설계 절차

## Purpose

AI가 업무 지식을 이해하도록 데이터 스키마와 비즈니스 규칙을 담은 온톨로지를 설계하고 검증한다.

## Steps

1. CQ(Competency Question)를 정한다. "AI가 이 정도는 답해야 한다"는 질문 목록이 설계 범위가 된다. LLM으로 초안을 만들 수 있지만 사람이 확인·검증한다
2. TBox(개념·클래스 정의)를 수립한다. 기존 DB 스키마는 강력한 TBox 출발점이다
3. 비정형 데이터는 벡터화해 저장하고, 정형 데이터에서 비즈니스 규칙을 뽑아 온톨로지에 반영한다. Top-Down과 Bottom-Up을 병행하고 Human-in-the-Loop로 검증한다
4. ABox(실제 지식 인스턴스)를 지식 그래프에 적재한다
5. CQ 커버리지로 검증한다. 수행할 수 없는 업무가 있으면 CQ나 TBox를 고친다
6. 도메인이 늘면 상위 공통 + 하위 도메인 특화의 계층화 온톨로지로 확장한다
7. 운영 중에는 CQ 커버리지 LLM 자동 평가, 파이프라인 상태 추적, 원클릭 롤백으로 품질을 관리한다
