# 단계별 AI 코드 리뷰 워크플로

## Purpose

AI 리뷰를 로컬 경량 리뷰와 MR 심층 리뷰로 나누고, 사람은 요구사항 구현 여부만 판단하게 해 리뷰 비용과 품질을 함께 잡는다.

## Steps

1. 개발자가 로컬에서 기본 코드 리뷰를 낮은 강도로 돌려 수정 부분만 빠르게 확인한다.
2. MR 을 올리면 서비스 특성과 장애 이력을 담은 자체 리뷰 스킬로 전체 소스와 서비스 로직을 심층 리뷰한다. 코멘트는 소스 라인 단위로 달아 MR 이력에 남긴다.
3. 결과를 Critical / Major / Minor 로 나눈다. Critical 은 반드시 고치고 Minor 는 개발자가 판단한다.
4. AI 리포트에는 실제로 일어나지 않는 이슈도 섞이므로, 고칠 것과 넘길 것은 사람이 고른다.
5. 승인자는 코드를 직접 보지 않고 MR 본문의 요구사항 구현 내용과 테스트 수행 여부를 읽고 요구사항·설계대로 구현됐는지 판단해 머지한다. 머지 권한은 PM·중간관리자에게만 준다.
6. 도입 초기에는 사람이 AI 리뷰 결과를 함께 검토하며 스킬을 튜닝하고, 안정된 뒤에 위임 범위를 넓힌다.
